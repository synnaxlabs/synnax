# Synnax X

Synnax X contains common Python utilities for Synnax, such as telemetry types, codecs,
and control primitives.

Synnax X is an internal dependency of the [`synnax`](https://pypi.org/project/synnax/)
Python client. Do not install it on its own. For guides, see the
[Synnax documentation](https://docs.synnaxlabs.com/). The source code is in the
[Synnax repository](https://github.com/synnaxlabs/synnax).
