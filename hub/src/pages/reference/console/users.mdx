Synnax uses role-based access control (RBAC). Each user is assigned a role that
determines what resources they can view, edit, or delete.

<Divider.Divider x />

## Registering Users

Register a user with the `Register a user` command in the
[Command Palette](/reference/console/ui-overview#search-and-command-palette).

<Video client:only="react" id="console/users/register" />

Select a role during registration. The new user can then log in with the registered
username and password.

<Divider.Divider x />

## Built-In Roles

Synnax provides five built-in roles that cover common access patterns. Built-in roles
cannot be deleted or renamed.

| Role         | Description                                                             | Key Capabilities                                                                                                       |
| ------------ | ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Owner**    | Full control of deployment, including user registration and security    | All actions on all resources; user management; security settings                                                       |
| **Engineer** | Full access to system configuration except user management              | Create/edit channels, projects, schematics, line plots, tasks, devices, ranges, tables, Arc code; view users and roles |
| **Operator** | View projects and visualizations; control hardware and data acquisition | Control hardware tasks; edit ranges and framers; view all resources; cannot modify system configuration                |
| **Host**     | For machines running the Synnax driver                                  | Manage devices, tasks, and Arc automations                                                                             |
| **Viewer**   | Read-only access to all resources                                       | View all resources; no edit or delete capabilities                                                                     |

<Divider.Divider x />

## Assigning Roles

Right-click the user in the Users Toolbar and select `Change role`. In the dialog,
select a role and click `Assign`.

You can also drag a user onto a role in the resource tree.

<Video client:only="react" id="console/users/modal-change-role" />

Root users cannot have their roles changed, and users cannot change their own roles.
