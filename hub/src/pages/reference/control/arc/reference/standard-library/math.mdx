The `math` module provides numerical primitives: running averages, running min/max, and
derivatives.

## `avg`

Computes a running average of input values, emitting the updated average on each input.
By default the average accumulates over every sample; set `duration` or `count` to reset
the window periodically.

<Params
  fn="math.avg"
  input="numeric"
  params={[
    {
      name: "duration",
      type: "i64 ns",
      description: "Reset the average after this much time elapses (such as `5s`).",
    },
    {
      name: "count",
      type: "i64",
      description: "Reset the average after this many samples.",
    },
  ]}
  output={{
    type: "numeric",
    description: "The running average, matching the input type.",
  }}
/>

```arc channels="sensor, output"
sensor -> math.avg{} -> output

// Reset by sample count or time window
sensor -> math.avg{count=100} -> output
sensor -> math.avg{duration=5s} -> output
```

<Divider.Divider x />

## `derivative`

Computes the rate of change of input values with respect to time. The output is always
`f64`, regardless of the input type.

<Params
  fn="math.derivative"
  input="numeric"
  output={{
    type: "f64",
    description: "The rate of change between consecutive samples.",
  }}
/>

```arc channels="sensor, rate_output"
sensor -> math.derivative{} -> rate_output
```
