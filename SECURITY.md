# Security policy

## Report a vulnerability

Do not open a public issue for a vulnerability. Report it privately through
[GitHub](https://github.com/synnaxlabs/synnax/security/advisories/new). Only the Synnax
team can read the report.

Tell us the affected component (the Core, the Console, the Driver, or a client), its
version, the steps to reproduce, and the effect. We reply within five business days.

## Supported versions

We fix vulnerabilities in the latest release. Use the latest version of each component.
