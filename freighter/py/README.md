# Freighter

Freighter is the transport library for Synnax. It gives one interface for unary and
streaming communication over HTTP and WebSockets.

Freighter is an internal dependency of the [`synnax`](https://pypi.org/project/synnax/)
Python client. Do not install it on its own. For guides, see the
[Synnax documentation](https://docs.synnaxlabs.com/). The source code is in the
[Synnax repository](https://github.com/synnaxlabs/synnax).
