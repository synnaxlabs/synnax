The Synnax Console is a desktop application for visualizing data, controlling hardware,
and managing a Synnax Core. It runs on Windows 11 and macOS Sequoia or later.

## Requirements

### Hardware

|             | Minimum                                             | Recommended                                          |
| ----------- | --------------------------------------------------- | ---------------------------------------------------- |
| **CPU**     | Intel Core i5 (8th gen) / AMD Ryzen 5 (3000 series) | Intel Core i7 (10th gen) / AMD Ryzen 7 (4000 series) |
| **RAM**     | 8 GB                                                | 16 GB or more                                        |
| **Storage** | 2 GB available                                      | 4 GB available (SSD recommended)                     |

### Graphics

The Console is GPU-intensive: high-frequency plotting and dense schematics need a
dedicated graphics card for smooth performance.

|             | Minimum                      | Recommended                      |
| ----------- | ---------------------------- | -------------------------------- |
| **GPU**     | NVIDIA GTX 1030 / AMD RX 550 | NVIDIA RTX 2060 / AMD RX 5600 XT |
| **VRAM**    | 2 GB                         | 6 GB or more                     |
| **DirectX** | Version 12                   | Version 12 Ultimate              |
| **OpenGL**  | Version 4.5                  | Version 4.6                      |

Integrated graphics (Intel Iris Xe, AMD Radeon Vega) work, but performance drops with
multiple high-frequency streams, long time ranges, or complex schematics.

### Display

Use a display of at least 1920x1080. A 4K display is preferred for extended use.
