## Connecting a New Core

Connecting to a new Core is as simple as clicking the **Add a Core** button and entering
your connection parameters.

<Video client:only="react" id="console/clusters/connect" />

### Parameters

<table>
  <thead>
    <tr>
      <th>Parameter</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>
        <b>Host</b>
      </td>
      <td>The hostname or IP address of the Core.</td>
    </tr>
    <tr>
      <td>
        <b>Port</b>
      </td>
      <td>The port number of the Core.</td>
    </tr>
    <tr>
      <td>
        <b>Secure</b>
      </td>
      {
        <td>
          Whether to use TLS when connecting to the Core. This parameter only works with
          secure Cores.
        </td>
      }
    </tr>
    <tr>
      <td>
        <b>Username</b>
      </td>
      <td>The username to use when connecting to the Core.</td>
    </tr>
    <tr>
      <td>
        <b>Password</b>
      </td>
      <td>The password to use when connecting to the Core.</td>
    </tr>
  </tbody>
