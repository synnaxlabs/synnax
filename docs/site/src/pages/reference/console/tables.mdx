Tables display live telemetry in a tabular format. They are useful for dashboards,
viewing many channels at once, and conditionally coloring values that exceed thresholds.

## Configuring the table

Click the table <Icon.Table /> button in the bottom-left corner to open the Component
Toolbar and configure the table.

### Text cells

Text cells display a line of text. You can change the alignment, weight, and size.

### Value cells

Value cells function like values on a schematic. They display live data and update as
new data arrives.

### Redlining a value

Redline a value to change its background color when it passes a threshold. In the cell's
`Redline` tab, click `Add band`, then set the threshold and the color of the band.

Each band has a threshold and a color. A band paints the values at or above its
threshold and below the next higher threshold. The base paints the values below every
threshold. By default, the base paints nothing.

- **Smooth** -> Blends the colors between thresholds instead of changing the color at
  each threshold.
- **Flash** (lightning icon) -> Makes the band blink between its color and the base
  while the value is in the band.
