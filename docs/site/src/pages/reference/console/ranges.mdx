[Ranges](/reference/concepts/ranges) are the primary means for organizing and accessing
the data stored in a Synnax Core. They identify and name a specific time interval, and
can be used to correlate metadata with channel telemetry.

<Divider.Divider x />

## Creating a Range

Click the `Create` button in the Ranges Toolbar and fill in the dialog, or run the
`Create a range` command in the
[Command Palette](/reference/console/ui-overview#search-and-command-palette).

<Video client:only="react" id="console/ranges/palette-create" />

### From a Plot Region

Select a region on a plot to annotate an event. The creation dialog fills the `From` and
`To` fields with the selected region.

<Video client:only="react" id="console/ranges/plot-create" />

<Divider.Divider x />

## Finding Existing Ranges

### Ranges Toolbar

The Ranges Toolbar on the left side of the Console shows the ranges you have favorited.
Click a range to load it.

<Video client:only="react" id="console/ranges/resources" />

### Range Explorer

The Range Explorer lists every range on your Core in a full tab, with search and label
filters. Search for it in the
[Search Palette](/reference/console/ui-overview#search-and-command-palette), or open it
from the Ranges Toolbar.

<Video client:only="react" id="console/ranges/explorer" />

### Search Palette

Type the name of a range into the
[Search Palette](/reference/console/ui-overview#search-and-command-palette).

<Video client:only="react" id="console/ranges/palette" />

<Divider.Divider x />

## Child Ranges

[Child ranges](/reference/concepts/ranges#child-ranges) segment a range into smaller
intervals. Set the parent range field in the creation dialog, or click `Add Child Range`
in the range overview page.
