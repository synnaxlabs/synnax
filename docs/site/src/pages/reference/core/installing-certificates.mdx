This page is a guide on how to install CA certificates on client machines to enable
communication with a Synnax Core using a self-signed certificate. Select your operating
system below.

<Fragment slot="linux">
## Linux

To start off, you'll need to pull the CA certificate from the Core. If you have ssh
access to the Core, you can use the `scp` command to pull the certificate:

```bash
scp user@core:/path/to/ca.crt /tmp/synnax-ca.crt
```

On Debian and Ubuntu, copy the certificate into the local CA directory and rebuild the
trust bundle:

```bash
sudo cp /tmp/synnax-ca.crt /usr/local/share/ca-certificates/synnax-ca.crt
sudo update-ca-certificates
```

On RHEL and Fedora, use the CA trust anchors directory instead:

```bash
sudo cp /tmp/synnax-ca.crt /etc/pki/ca-trust/source/anchors/synnax-ca.crt
sudo update-ca-trust
```

On a machine where you can't change the trust store, point the Driver at the certificate
file instead. The Driver service reads `/etc/synnax/driver.env` at start, so add:

```bash
GRPC_DEFAULT_SSL_ROOTS_FILE_PATH=/tmp/synnax-ca.crt
```

</Fragment>
<Fragment slot="windows">
## Windows

To start off, you'll need to pull the CA certificate from the Core. Once you have the
certificate, you can install it using the `Import-Certificate` command. Note that you
may need to open PowerShell as an administrator to run the command.

```powershell
Import-Certificate -FilePath PATH_TO_CA_CRT -CertStoreLocation Cert:\LocalMachine\Root
```

</Fragment>
<Fragment slot="macos">
## macOS

To start off, you'll need to pull the CA certificate from the Core. If you have ssh
access to the Core, you can use the `scp` command to pull the certificate:

```bash
scp user@core:/path/to/ca.crt /tmp/synnax-ca.crt
```

Otherwise, you can copy and paste the certificate into a new file. Open a new terminal
and run the following command:

```bash
sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain /tmp/synnax-ca.crt
```

The Driver does not read the Keychain. Point it at the certificate file instead:

```bash
export GRPC_DEFAULT_SSL_ROOTS_FILE_PATH=/tmp/synnax-ca.crt
```
