## Function Declaration

```arc
func name{inputs} (trigger) output {
// body
}
```

| Part        | Required | Description          |
| ----------- | -------- | -------------------- |
| `func`      | Yes      | Keyword              |
| `name`      | Yes      | Function identifier  |
| `{inputs}`  | No       | The function inputs  |
| `(trigger)` | No       | The function trigger |
| `output`    | No       | Return type          |
| `{ body }`  | Yes      | Function body        |

## Basic Functions

A function with inputs and an output:

```arc
func add(x f64, y f64) f64 {
    return x + y
}
```

A function with no return value:

```arc
func log_value(value f64) {
    debug_channel = value
}
```

## Inputs

- Braces `{}` for the `flow` side: inputs set when you instantiate the function in a
  flow.
- Parens `()` for the `func` side: inputs passed when you call the function.

```arc
func filter{threshold f64} (value f64) f64 {
    if value > threshold {
        return value
    }
    return 0.0
}
```

Here `threshold` is set in the braces and `value` is the trigger.

Input parameters can be literals or channel references:

```arc
func controller{
    setpoint f64,      // literal or channel
    sensor chan f64,   // channel reference
    output chan f64,   // channel reference
} (enable u8) f64 {
    value := sensor
    if enable {
        output = value - setpoint
    }
    return value
}
// Static setpoint
sensor -> controller{setpoint=100.0, sensor=temp, output=cmd}
// Setpoint driven by a channel
sensor -> controller{setpoint=setpoint_input, sensor=temp, output=cmd}
```

### Optional Inputs

Optional inputs have default values and must be trailing:

```arc
func clamp(value f64, min f64 = 0.0, max f64 = 1.0) f64 {
    if value < min {
        return min
    }
    if value > max {
        return max
    }
    return value
}
```

## Output Types

### Single Unnamed Output

```arc
func double(value f64) f64 {
    return value * 2
}
```

### Single Named Output

```arc
func compute(x f64)result f64 {
    result = x * 2
    return result
}
```

### Multiple Named Outputs

A function may declare more than one named output. Each output is set in the body and
routed to its own destination at the call site. Use
[routing tables](/reference/control/arc/reference/flow#output-routing) to connect
multiple outputs:

```arc
func split(value f64) (high f64, low f64) {
    if value > 50.0 {
        high = value
    } else {
        low = value
    }
}

sensor -> split{} -> {
    high: alarm{},
    low: logger{}
}
```

## Calling Functions

Arc has two calling conventions depending on context: parentheses inside function
bodies, and braces to instantiate a function in a flow statement.

## Stateful Variables in Functions

Functions can declare stateful variables that persist across invocations:

```arc
func counter() i64 {
    count $= 0 // persists
    count = count + 1
    return count
}
```

Each function instantiation has its own state:

```arc
// Two separate counters with independent state
time.interval {
    100ms
} -> counter{} -> count1
time.interval{200ms} -> counter{} -> count2
```

## Channel Operations in Functions

Functions can read from and write to channels:

```arc
func controller{input chan f64, output chan f64, threshold f64} () {
    value := input // read (non-blocking)
    if value > threshold {
        output = value // write (queued)
    }
}
```

Functions can also reference global channels by name:

```arc
func monitor() {
    if ox_pt_1 > 500 {
        alarm_status = 1
    }
}
```

<Note.Note variant="info">
  Channel reads in function bodies are non-blocking snapshots. They return the latest
  value or zero if no data exists.
</Note.Note>

## Multi-Input Functions

Use [routing tables](/reference/control/arc/reference/flow#input-routing) to map
multiple sources to input parameters:

```arc
func average(a f64, b f64) f64 {
    return (a + b) / 2.0
}

{
    sensor1: a,
    sensor2: b
} -> average{} -> avg_output
```

The routing table maps channel names to parameter names.

## Restrictions

| Restriction             | Description                                               |
| ----------------------- | --------------------------------------------------------- |
| No closures             | Functions cannot capture variables from enclosing scope   |
| No nested functions     | Functions cannot be defined inside other functions        |
| No partial application  | All required arguments must be provided                   |
| Explicit returns        | Functions with return types require `return` statements   |
| Flow inputs = constants | Flow input values must be literals or channel identifiers |

<Divider.Divider x />

## Recursion

Recursion is allowed but must have a termination condition:

```arc
func factorial(n i64) i64 {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}
```

<Note.Note variant="warning">
  Unbounded recursion causes a stack overflow at runtime.
</Note.Note>

## Built-in Functions

Built-in functions require no `import` or module prefix.

### len

Returns the length of a series or string.

```arc
data := [1.0, 2.0, 3.0]
length := len(data) // 3 (i64)

msg := "hello"
chars := len(msg) // 5 (i64)
```

| Parameter   | Type              | Description                 |
| ----------- | ----------------- | --------------------------- |
| input       | `series` or `str` | Value to measure            |
| **Returns** | `i64`             | Number of elements or bytes |
