The `control` module provides runtime control over write authority, letting a program
promote or release writes that target shared channels.

## `set_authority`

Dynamically changes the control authority of write channels at runtime. Higher authority
values take priority, and setting the authority to `0` releases control.

<Params
  fn="control.set_authority"
  params={[
    {
      name: "value",
      type: "u8",
      required: true,
      description:
        "Authority level `0`-`255`. Higher values take priority; `0` releases control.",
    },
    {
      name: "channel",
      type: "chan",
      description:
        "The write channel to target. If omitted, applies to all write channels.",
    },
  ]}
  output={{
    description: "None; changes authority as a side effect and emits no value.",
  }}
/>

```arc channels="trigger, valve_cmd"
// `flow` only
trigger -> control.set_authority{value=255}

// Target a specific channel; value=0 releases control
trigger -> control.set_authority{value=255, channel=valve_cmd}
```
