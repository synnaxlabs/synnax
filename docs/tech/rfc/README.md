# Requests for comment

An RFC records a design decision: the problem, the options weighed, the choice made, and
the alternatives rejected. The corpus is the design history of the platform. Read the
RFC for a component before you change it, and write one before you re-architect it.

Numbers are permanent and gapless. Claim the next free number when you open the pull
request. `docs/tech/rfc/CLAUDE.md` holds the file name, front matter, heading, and prose
rules.

The table below is generated by `scripts/gen_rfc_index.py`. Run it after you add an RFC.
Dates record when the design started, not when it landed, so the table is not a shipping
order. `git log --follow` reaches history from before the 2026-08 rename.
