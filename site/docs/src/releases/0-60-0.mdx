Synnax v0.60 gets licenses from the Synnax portal. A Core needs a license again, and the
Core accepts only signed license keys. Get your license before you upgrade, and read the
breaking changes first.

<Divider.Divider x />

### Licenses from the Synnax portal

Your organization's admin gets licenses at
[portal.synnaxlabs.com](https://portal.synnaxlabs.com). For each Core, copy the
fingerprint from the activation screen of the Console or from the log of the Core,
activate the license on the portal, and load the `.lic` file that it downloads. To move
a license to a different computer, release its seat on the portal. See
[Activate a license](/reference/enterprise/license).

### Breaking changes

#### A Core needs a license again

A Core without a license starts, but it refuses every request except login, the
connectivity check, and the license requests. The Console shows an activation screen.
The 50-channel limit for a Core without a license, which Core 0.59.2 brought back, is
removed.

#### Numeric license keys are not accepted

The Core refuses the old numeric keys, such as `######-########-##########`. Get a
signed license key from the Synnax portal.

#### Get the license before you upgrade

Activate the license for each Core on the portal before you upgrade it. On Core 0.59,
the "Show license info" command copies the fingerprint. After the upgrade, you cannot go
back to 0.59, because Core 0.60 migrates the stored data. If you are not ready to change
your license, stay on Core 0.59. See
[numeric license keys](/reference/enterprise/license#numeric-license-keys).

#### A refused key does not stop the start

When the Core refuses the key from `--license-key`, `--license-file`, or
`SYNNAX_LICENSE_KEY`, it logs the reason and starts with the keys that it stored, or
without a license. Before, the Core did not start. Check the log after you start the
Core.

#### Docker needs a fixed MAC address

The license is bound to the MAC address of the container. Start the container with
`--mac-address`, and keep the same address when you recreate it. Otherwise the
fingerprint changes, and the license no longer applies. See
[Docker](/reference/enterprise/license#docker).

#### Upgrade the Console with the Core

A Console older than 0.60 shows errors instead of the activation screen when it connects
to a Core 0.60 without a license. Upgrade the Console and the Core together.
