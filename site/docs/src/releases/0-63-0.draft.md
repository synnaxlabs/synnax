### Breaking changes in 0.63

#### Colors

- Label, range, log channel, table cell, panel, and schematic colors are color
  references: a named color, `{ type: "named", key }`, or a fixed color,
  `{ type: "fixed", value }`. The update keeps each stored color as a fixed color. In a
  schematic, these stay color values:
  - the stroke of a toggle, static, or light symbol, such as a valve or a pump
  - the colors that a state draws: the on color of a light, the color of each state of a
    select or a state indicator, and the stroke and fill of each region in the state
    overrides of a custom symbol
  - each staleness color
  - the redline scale of a value
- TypeScript: these colors hold a reference, and a create or a color change takes one.
  Change `color: "#FF0000"` to `color: { type: "fixed", value: "#FF0000" }`.
- Python: these fields hold a `NamedRef` or a `FixedRef`:
  - `Label.color` and `Range.color`
  - `sy.log.ChannelEntry.color` and `sy.Panel.color`
  - the colors of `sy.table.TextCellConfig` and `sy.table.ValueCellConfig`
  - every other stroke, fill, text, level, and axis color of the schematic `*NodeConfig`
    and `*EdgeConfig` types, such as `TankNodeConfig.fill_color`

  `labels.create(name=..., color=...)`, `ranges.create(...)`, `sy.Range(...)`, and
  `set_color` still take a color, such as `"#FF0000"`, and keep it as a fixed color. A
  model that you build, such as a `sy.Label`, takes a reference: use
  `sy.color.to_ref("#FF0000")`.
