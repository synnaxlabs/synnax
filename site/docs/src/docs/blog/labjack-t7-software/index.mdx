You have a LabJack T7 and a thermocouple. You want two things: a live plot of the
temperature, and a file of every sample when the test ends.

On Windows, LabJack's [LJLogM](https://support.labjack.com/docs/t7-software-options) and
[LJStreamM](https://support.labjack.com/docs/ljstreamm-windows-only) do this. They do
not run on macOS. LabJack's advice for Mac users is to
[run them in a Windows virtual machine](https://labjack.com/blogs/news/logm-and-streamm-on-macos-with-parallels).
On any computer, you can use Python and the LJM library, but then you write the plot,
the logging, and the export yourself.

This walkthrough uses Synnax Desktop. It runs on macOS and Windows, finds the T7 for
you, and records every sample while you watch the plot. You write no code.

## What you need

- A LabJack T7 on USB, Ethernet, or Wi-Fi. A T4 works for analog inputs, but only the T7
  reads thermocouples.
- A type K thermocouple.
- A Mac or a Windows PC.
- The current
  [LJM library](https://support.labjack.com/docs/ljm-software-installer-downloads-t4-t7-t8-digit)
  from LabJack.
- [Synnax Desktop](/reference/get-started/install-desktop). It is free for commercial
  use, up to 50 channels.

Connect the yellow positive lead of the thermocouple to `AIN0`, and the red negative
lead to `GND`.

<Wiring />

## 1. Open a project

Install LJM, then install Synnax Desktop and open it. Select **New project**, enter a
name, and select **Create**.

Desktop runs the Synnax Core and the Driver on your computer. The Driver is the part
that talks to the T7.

## 2. Configure the T7

Open the **Devices** toolbar from the bar on the left, and expand the Driver. The Driver
looks for LabJack devices every few seconds. The T7 shows under it with its serial
number in its name, such as `LJM_dtT7-7383`. Right-click it and select **Configure**.

Enter a **Name**, such as `Lab T7`, and an **Identifier**, such as `t7`. The identifier
is a prefix for each channel on the device, so the thermocouple channel is `t7_AIN0`.

Select **Save and create read task**.

## 3. Read the thermocouple

The read task opens with one channel on `AIN0`. Set **Channel type** to
**Thermocouple**. The defaults fit a type K thermocouple: the input is single-ended, and
cold-junction compensation uses the temperature sensor in the T7. Set **Temperature
units** to **Celsius**.

The task samples at 10 Hz. Select the play button to start it. The status changes to
"Started task".

## 4. Plot it live

Select **+** at the right of the tab bar, then **Line plot**. Press **V** to open the
toolbar, and on the **Data** tab, select `t7_AIN0` in **Y1**. The plot shows the last 30
seconds and adds each new sample when it arrives. Hold the thermocouple in your hand,
and the line climbs.

## 5. Record and export

You do not need a separate logging step. **Data saving** is on by default, so the Core
records each sample that the task reads.

To export part of a run, hold **Option** (**Alt** on Windows) and drag across the plot.
Right-click the selection and select **Download region as CSV**. To keep the run, select
**Create range from selection**. A range gives the run a name, and you can open it again
in any plot.

## Limits

<Note.Note variant="info">

- Synnax supports the LabJack T4 and T7. It does not support the T8 yet.
- Synnax connects to LabJack devices on macOS and Windows, not on Linux.
- With a thermocouple in a task, the Driver reads one sample at a time. That suits slow
  signals such as temperature. A task with only analog inputs streams at up to 50,000
  Hz.
- Synnax Desktop is free up to 50 channels.

</Note.Note>
