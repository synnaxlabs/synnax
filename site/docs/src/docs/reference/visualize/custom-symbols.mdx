A custom symbol is an SVG drawing that you add to a
[schematic](/reference/visualize/schematics), like a built-in symbol. Use one when your
hardware has no built-in symbol, such as a special valve or the outline of a vehicle.
Custom symbols live in symbol groups, which every schematic on the Core can use.

Each symbol holds:

- **Parts** -> named sets of shapes in the drawing, such as the body of a valve.
- **States** -> what the symbol shows, such as open or closed. Each node on a schematic
  reads its states from channels.
- **Looks** -> the fill, stroke, and visibility of a part, for all states or for each
  state.
- **Commands** -> named values that the symbol writes, such as 1 for **Open**.
- **Clicks** -> the command that a click on a part, or on the whole drawing, sends.

The symbol holds the design. Each node of the symbol on a schematic holds its channels,
label, color, and size. When you edit a symbol, every node that draws it shows the
change.

## Create a symbol group

1. Open a schematic and turn on editing.
2. Press **V** to open the component toolbar, then select the **Symbols** tab.
3. Click **Create symbol group**.
4. Enter a name, then click **Save**.

## Create a symbol

1. In the **Symbols** tab, select your symbol group.
2. Click **Create symbol**.
3. Drop an SVG file on the dialog, or click it to select a file. The file name becomes
   the symbol name.
4. Under **Parts**, select a part. Then set its **Fill**, **Stroke**, and **Visible** in
   the inspector on the right of the dialog.
5. Optional: to make the symbol clickable, add commands and clicks. See
   [make a symbol clickable](#make-a-symbol-clickable).
6. Optional: under **Handles**, click <Icon.Add /> to add a connection point. Drag it to
   the edge of the drawing.
7. Click **Create**.

After you load a file, you cannot replace it. To use a different drawing, create a new
symbol.

### Start from a built-in symbol

To change a built-in symbol, copy it into a custom group:

1. In the **Symbols** tab, right-click a built-in symbol.
2. Select **Duplicate to**, then select a group, or **New group…**.

The copy is named after the built-in symbol with **(copy)** at the end, and opens in the
symbol editor. It keeps the states, commands, clicks, and looks of the built-in symbol.
Start from a built-in symbol when you want a click that toggles between two commands,
like a valve: the editor cannot add a toggle.

## Make a symbol clickable

A click sends a command. A command writes one value, to the channel of a state or to a
channel of its own.

1. In the symbol editor, click <Icon.Add /> next to **Commands**.
2. In the inspector, select the **State** that the command writes, or **None**.
3. Under **Value**, select **Fixed** and set the value, or select **Ask**.
4. Click <Icon.Add /> next to **Clicks**.
5. In the inspector, select the **Target**: **Whole drawing** or a part.
6. Select the **Command** that a click on the target sends.
7. Click **Create** or **Save**.

Each part, and the whole drawing, can have one click. Double-click the name of a state
or command to rename it.

An **Ask** command needs a state. When an operator clicks the symbol, it asks for the
value: a menu of the entries of its enumeration, or a number field.

<Divider.Divider x />

## Color a symbol by state

1. In the symbol editor, select a part, or **Whole drawing**.
2. Click the button next to **Fill** or **Stroke**, then select a paint, such as
   **Color** or **Node color**.
3. To give each state its own paint, click **By state** next to the field. Then set the
   paint for each value.
4. Use the **Preview** bar under the drawing to show each value.
5. Click **Create** or **Save**.

A look on a part wins over a look on the whole drawing. On the same part, a look for one
value wins over a look for all values. See [paints](#paints) for each paint.

## Add the symbol to a schematic

1. In the **Symbols** tab, select the group.
2. Click the symbol to add it at the center of the schematic, or drag it to a position.
3. Select the new node, then open the **Telemetry** tab of its properties.
4. For each state, set the **Source**. Select **Channel**, then select the **Channel**
   that the state reads, and the **Command channel** that its commands write.
5. If the symbol has commands with no state, open the **Control** tab. Under
   **Commands**, select a channel for each command.

To send a command, turn off editing and click the node. A node with no channel for a
command does nothing when you click it.

<Divider.Divider x />

## Edit a symbol

1. Right-click the symbol in the **Symbols** tab and select **Edit**. You can also
   select a node of the symbol and click <Icon.Edit /> next to its properties tabs.
2. Change the settings.
3. Click **Save**.

Every node that draws the symbol shows the change. When schematics use the symbol, the
Console asks you to confirm the save first. The dialog lists each schematic and what
each node loses, such as the binding of a state that you removed.

<Divider.Divider x />

## Share symbols

To export, right-click a symbol and select **Export** to save a `.json` file. To export
a whole group, right-click the group and select **Export** to save a `.zip` file.

To import, select a group and click **Import symbol** to add one or more `.json` files.
Click **Import symbol group** to add a `.zip` file or its unzipped folder.

An import always makes a new symbol. It does not change a symbol that is already on the
Core, so importing the same file two times makes two symbols.

<Divider.Divider x />

## Delete symbols and groups

Right-click a symbol or a group and select **Delete**. Deleting a group deletes every
symbol in it.

You cannot delete a symbol that a node on a schematic draws. The error names a schematic
that uses it. First change the symbol of each node: see
[change the type of a symbol](/reference/visualize/schematics#change-the-type-of-a-symbol).

## Symbol editor reference

### States

A new symbol has one state, **Active**, with the values **Base** (0) and **Active** (1).
Click <Icon.Add /> next to **States** to add a state. A state that you remove takes its
looks, its commands, and their clicks with it. When the state has uses, the Console asks
you to confirm first.

A state copied from a built-in symbol has an enumeration that names its values, such as
**Closed** and **Open**. Each node can replace the enumeration, the match, and the
default of a state. See [node properties](#node-properties).

### Commands

| Field | Description                                                                                                                    |
| ----- | ------------------------------------------------------------------------------------------------------------------------------ |
| State | The state whose **Command channel** the command writes. **None** writes to the channel set on the **Control** tab of the node. |
| Value | **Fixed** writes one value. **Ask** asks the operator for the value on each click. **Ask** needs a state.                      |

### Clicks

| Field   | Description                                   |
| ------- | --------------------------------------------- |
| Target  | **Whole drawing** or a part.                  |
| Command | The command that a click on the target sends. |

A toggle, copied from a built-in symbol, sends the command whose value differs from the
value of the state. It shows a menu of the two commands when the state has no data, when
the value matches neither command, or when the last command does not match the state.

### Parts

Synnax finds the parts of the drawing from its colors. Shapes with the same stroke and
fill are one part, named **Part 1**, **Part 2**, and so on. The first entry, **Whole
drawing**, has looks that apply to all shapes.

With **Whole drawing** selected, click a shape in the preview to select its part, or to
add a part from it. With a part selected, a click adds a shape to the part or removes
it. A click on a shape inside a group of the part takes the group out of the part. A
click on a shape inside a group of another part selects that part. Click <Icon.Add /> to
add a part. Double-click a part name to rename it.

When the shapes of a part sit in one group of the drawing, click **Select parent group**
in the inspector to make that group the part. **Alt**+click (**Option**+click on macOS)
a shape to do the same with the group around it. On a shape that the part holds, each
**Alt**+click takes the part one group higher.

### Paints

| Paint       | Description                                                                |
| ----------- | -------------------------------------------------------------------------- |
| Drawing     | The shapes keep the colors of the drawing. The default.                    |
| Color       | One color.                                                                 |
| State color | Each state draws the color of its enumeration entry.                       |
| Contrast    | Each state draws black or white, whichever reads on its entry color.       |
| Node color  | Each node sets the color, with **Color** on the **Style** tab of the node. |

**State color** and **Contrast** need a state with an enumeration, such as a state
copied from a built-in symbol. **Visible** shows or hides the part.

### Handles

A handle is a point where connection lines attach. Drag a handle in the preview, then
select the side of the symbol it faces: left, right, top, or bottom.

### Properties

| Field        | Description                                                                                      |
| ------------ | ------------------------------------------------------------------------------------------------ |
| Scale        | The size of the symbol when you add it to a schematic, from 5% to 1000%.                         |
| Scale stroke | When on, lines get thicker as the symbol gets larger. Off by default, so lines keep their width. |

### Preview

Press **=** to zoom in, **-** to zoom out, and **0** to reset the zoom. You can also
scroll to zoom, and **Shift**+drag or middle-drag to pan. Press **Ctrl+Enter**
(**Cmd+Enter** on macOS) to save.

### SVG files

Use one SVG file with an `<svg>` root element. Give parts that change color together the
same stroke and fill colors, so Synnax puts them in one part.

Draw with vector shapes. The Console removes scripts, event handlers, `foreignObject`
elements, and links to anything outside the file, so embedded and linked images do not
import.

### Node properties

The **Telemetry** tab of a node has a section for each state of its symbol:

| Field           | Description                                                                                                                                             |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Source          | **None**, **Channel**, or **Local**. A state with no source shows its default value.                                                                    |
| Channel         | The channel that the state reads.                                                                                                                       |
| Command channel | The channel that the commands of the state write.                                                                                                       |
| Value           | With a **Local** source, the value of the state. A command sets it.                                                                                     |
| Match           | **Exact** reads the value as it is. **Within** reads a value from **Min value** up to, but not including, **Max value** as 1, and any other value as 0. |
| Enumeration     | Replaces the enumeration of the state.                                                                                                                  |
| Default         | The value that the node shows when it has no data.                                                                                                      |

Click **Reset to symbol** to remove the changes to **Match**, **Enumeration**, and
**Default**.

The **Control** tab has a channel for each command with no state. Turn off **Clickable**
to stop clicks on the node. For **Delay** and **Control chip**, see the
[Control tab](/reference/visualize/schematics#control-tab) of a schematic.

## Troubleshooting

### The Console shows "Failed to read file"

<Problem.Body>
<Problem.Cause>

The Console cannot read the file as an SVG drawing. The description of the message says
why.

</Problem.Cause>
<Problem.Fix>

- **"The file is not an SVG."** -> select a file with the `.svg` extension.
- **"The file is empty."** -> export the drawing again from your drawing program.
- **"The file does not contain a valid SVG image."** -> open the file in a text editor
  and check that it starts with an `<svg>` element and has no errors.

</Problem.Fix>
</Problem.Body>

### A node does nothing when I click it

<Problem.Body>
<Problem.Cause>

Editing is on, the command of the click has no channel, or the node is not clickable.

</Problem.Cause>
<Problem.Fix>

- Turn off editing.
- On the **Telemetry** tab, set the **Command channel** of the state that the command
  writes. For a command with no state, set its channel on the **Control** tab.
- On the **Control** tab, turn on **Clickable**.
- In the symbol editor, check that the part or the whole drawing has a click.

If the node still does nothing, see
[control troubleshooting](/reference/control/troubleshooting#a-click-on-a-valve-does-nothing).

</Problem.Fix>
</Problem.Body>

### A node shows a warning

<Problem.Body>
<Problem.Cause>

The node cannot draw its symbol. The text of the warning says why.

</Problem.Cause>
<Problem.Fix>

- **"Missing symbol"** -> the Core does not have the symbol, such as after you import a
  schematic from another Core.
  [Change the symbol](/reference/visualize/schematics#change-the-type-of-a-symbol) of
  the node.
- **"Failed to load symbol"** -> your user cannot read symbols, or the Console has no
  connection to the Core. Ask an administrator for access to symbols, or connect again.
- **"Invalid symbol"** -> the stored drawing is not a valid SVG. Create a new symbol
  from a valid SVG file, then change the symbol of the node to it.

</Problem.Fix>
</Problem.Body>
