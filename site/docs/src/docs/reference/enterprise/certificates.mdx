A computer must trust the CA certificate of a Synnax Core that uses a
[self-signed certificate](/reference/enterprise/tls#use-a-self-signed-certificate).
Install the CA certificate on each computer that runs the Console, a browser, a
standalone Driver, a Python client, or a TypeScript client in Node.js. A Core with a
certificate from a public CA, or from a CA that your computers already trust, needs none
of this.

<Divider.Divider x />

## Copy the CA certificate

The CA certificate is `ca.crt` in the certificate folder of the Core:

- **Linux and macOS** -> `/usr/local/synnax/certs/ca.crt`
- **Windows service** -> `C:\ProgramData\Synnax\certs\ca.crt`
- **Docker** -> `/usr/local/synnax/certs/ca.crt` in the container. Copy it out with
  `docker cp synnax:/usr/local/synnax/certs/ca.crt ./synnax-ca.crt`.

If the Core started with `--certs-dir`, the file is in that folder. Copy only `ca.crt`.
Never copy `ca.key` to another computer.

## Install the certificate

<Platform.Tabs exclude={["Docker"]}>

<Fragment slot="Linux">

On Debian and Ubuntu:

```bash
sudo cp synnax-ca.crt /usr/local/share/ca-certificates/synnax-ca.crt
sudo update-ca-certificates
```

On RHEL and Fedora:

```bash
sudo cp synnax-ca.crt /etc/pki/ca-trust/source/anchors/synnax-ca.crt
sudo update-ca-trust
```

The Console, Chrome, a standalone Driver, the Python client, and the TypeScript client
in Node.js use this store. Firefox on Linux does not: in Firefox, open **Settings**,
search for "certificates", click **View Certificates**, and import the file on the
**Authorities** tab.

</Fragment>

<Fragment slot="Windows">

In PowerShell as an administrator:

```powershell
Import-Certificate -FilePath synnax-ca.crt `
  -CertStoreLocation Cert:\LocalMachine\Root
```

The Console, browsers, a standalone Driver, the Python client, and the TypeScript client
in Node.js use this store.

</Fragment>

<Fragment slot="macOS">

```bash
sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain synnax-ca.crt
```

The Console, browsers, the Python client, and the TypeScript client in Node.js use the
Keychain. The Driver does not. Run
`sudo synnax-driver login --ca-cert /path/to/synnax-ca.crt`, then restart the service.

</Fragment>

</Platform.Tabs>

<Note.Note variant="warning">
  A CA certificate file given to the Driver replaces every certificate the Driver
  trusts, and turns TLS on. Give one only for a Core with a certificate from your own
  authority.
</Note.Note>

## Bun, Deno, and older Node.js

Bun, Deno, and Node.js before 22.15 or 23.10 do not read the operating system store.
Give the TypeScript client the CA certificate in
[`caCert`](/reference/client/connect#connect-with-tls). Deno takes the CA certificate
with `--cert` instead. In Node.js, you can also start the client with the CA certificate
in `NODE_EXTRA_CA_CERTS`:

```bash
NODE_EXTRA_CA_CERTS=/path/to/synnax-ca.crt node app.js
```
