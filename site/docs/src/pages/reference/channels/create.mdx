Most [channels](/reference/channels) come from
[tasks](/reference/channels#channels-that-tasks-create), which create their channels for
you. Create a channel yourself to store data from a script, or to send a live signal
with a virtual channel. To compute values from other channels, create a
[calculated channel](/reference/channels/calculated).

<Divider.Divider x />

## Choose an index

Each data channel needs an index channel for its timestamps. You set the index when you
create the data channel, and you cannot change it later.

- Data channels that you write at the same times can share one index. For example,
  sensors that one script reads in the same loop.
- Data channels that you write at different times need different indexes. Give each
  [command channel](/reference/hardware/tasks#command-channels) its own index.
- Virtual channels have no index.

<Note.Note variant="warning" className="compact">
  Create the index channel before the data channels that use it.
</Note.Note>

## Create index and data channels

<Client.Tabs exclude={["cpp"]}>

  <Fragment slot="console">

1. Click <Icon.Add /> in the
   [channels toolbar](/reference/get-started/ui-overview#channels), or run the "Create
   channel" command in the
   [command palette](/reference/get-started/ui-overview#search-and-command-palette).
2. Enter a name.
3. For an index channel, turn on **Is index**. The data type changes to `timestamp`.
4. For a data channel, select the data type and the index channel.
5. Click **Create**. To keep the dialog open for the next channel, turn on **Create
   more** first.

<Video id="client/channels/create" />

  </Fragment>

  <Fragment slot="python">

```python
import synnax as sy

tank_time = client.channels.create(
    name="tank_time",
    data_type=sy.DataType.TIMESTAMP,
    is_index=True,
    retrieve_if_name_exists=True,
)

tank_pressure, tank_temperature = client.channels.create(
    [
        sy.Channel(
            name="tank_pressure",
            data_type=sy.DataType.FLOAT32,
            index=tank_time.key,
        ),
        sy.Channel(
            name="tank_temperature",
            data_type=sy.DataType.FLOAT32,
            index=tank_time.key,
        ),
    ],
    retrieve_if_name_exists=True,
)
```

`create` takes one channel or a list of channels. One call with a list is faster than
many calls with one channel each.

With `retrieve_if_name_exists=True`, `create` returns the existing channel when a
channel with the same name exists. It does not compare the data type or the index. Use
this option to run the same script many times.

  </Fragment>

  <Fragment slot="typescript">

```typescript
import { DataType } from "@synnaxlabs/client";

const tankTime = await client.channels.create(
  {
    name: "tank_time",
    dataType: DataType.TIMESTAMP,
    isIndex: true,
  },
  { retrieveIfNameExists: true },
);

const [tankPressure, tankTemperature] = await client.channels.create(
  [
    { name: "tank_pressure", dataType: DataType.FLOAT32, index: tankTime.key },
    { name: "tank_temperature", dataType: DataType.FLOAT32, index: tankTime.key },
  ],
  { retrieveIfNameExists: true },
);
```

`create` takes one channel or an array of channels. One call with an array is faster
than many calls with one channel each.

With `retrieveIfNameExists: true`, `create` returns the existing channel when a channel
with the same name exists. It does not compare the data type or the index. Use this
option to run the same script many times.

  </Fragment>

## Create a virtual channel

A [virtual channel](/reference/channels#virtual-channels) has no index, so you can
create it at any time.

<Client.Tabs exclude={["cpp"]}>

  <Fragment slot="console">

Open the **Create channel** dialog, enter a name, and select the data type. Turn on
**Virtual**, then click **Create**.

  </Fragment>

  <Fragment slot="python">

```python
start_cmd = client.channels.create(
    name="start_cmd",
    data_type=sy.DataType.BOOLEAN,
    virtual=True,
)
```

  </Fragment>

  <Fragment slot="typescript">

```typescript
const startCmd = await client.channels.create({
  name: "start_cmd",
  dataType: DataType.BOOLEAN,
  virtual: true,
});
```

  </Fragment>
