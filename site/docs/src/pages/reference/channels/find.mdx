## Find a channel by name or key

<Client.Tabs>

  <Fragment slot="console">

Find a channel in the [channels toolbar](/reference/get-started/ui-overview#channels).
To search by name, open the
[search palette](/reference/get-started/ui-overview#search-and-command-palette) and type
part of the name. Select a result to open the channel in a line plot. A virtual channel
opens in a log.

  </Fragment>

  <Fragment slot="python">

```python
# One channel, by name or by key
tank_pressure = client.channels.retrieve("tank_pressure")
tank_pressure = client.channels.retrieve(tank_pressure.key)

# Many channels, by names or by keys
channels = client.channels.retrieve(["tank_pressure", "tank_temperature"])
channels = client.channels.retrieve([tank_pressure.key, tank_temperature.key])
```

When you pass one name or key, `retrieve` returns one channel. It raises
`sy.NotFoundError` when no channel matches. When you pass a list, `retrieve` returns a
list and leaves out the channels that it does not find.

Pass names or keys, not both in one list. A key never changes, but a name can change.
Store keys in programs that run for a long time.

  </Fragment>

  <Fragment slot="typescript">

```typescript
// One channel, by name or by key
const tankPressure = await client.channels.retrieve("tank_pressure");
const sameChannel = await client.channels.retrieve(tankPressure.key);

// Many channels, by names or by keys
const byName = await client.channels.retrieve(["tank_pressure", "tank_temperature"]);
const byKey = await client.channels.retrieve([tankPressure.key, sameChannel.key]);
```

When you pass one name or key, `retrieve` returns one channel. It throws a
`NotFoundError` when no channel matches. When you pass an array, `retrieve` returns an
array and leaves out the channels that it does not find.

Pass names or keys, not both in one array. A key never changes, but a name can change.
Store keys in programs that run for a long time.

  </Fragment>

</Client.Tabs>

## Find channels by pattern

A name that is not a valid [channel name](/reference/channels#names) is a regular
expression, in [Go RE2 syntax](https://github.com/google/re2/wiki/Syntax). The pattern
must match the full name, unless it starts with `^` or ends with `$`. For example,
`tank_.*` matches `tank_pressure` and `tank_time`, but not `ox_tank_pressure`.

<Client.Tabs exclude={["console"]}>

  <Fragment slot="python">

```python
# Returns list[sy.Channel]
tank_channels = client.channels.retrieve(["tank_.*"])
```

Put the pattern in a list. With a pattern that is not in a list, `retrieve` raises
`sy.MultipleFoundError` when more than one channel matches.

  </Fragment>

  <Fragment slot="typescript">

```typescript
// Returns Channel[]
const tankChannels = await client.channels.retrieve(["tank_.*"]);
```

Put the pattern in an array. With a pattern that is not in an array, `retrieve` throws a
`MultipleFoundError` when more than one channel matches.

  </Fragment>

</Client.Tabs>

## Search and filter channels

The TypeScript client can search channels by a part of their name, and filter them by
their properties.

<Client.Tabs exclude={["console", "python"]}>

  <Fragment slot="typescript">

```typescript
import { DataType } from "@synnaxlabs/client";

// The ten best matches for "pressure"
const matches = await client.channels.retrieve({ searchTerm: "pressure", limit: 10 });

// All float32 data channels
const floats = await client.channels.retrieve({
  dataTypes: [DataType.FLOAT32],
  isIndex: false,
});
```

| Filter         | Returns channels that                                             |
| -------------- | ----------------------------------------------------------------- |
| `searchTerm`   | Have a name that is similar to the term.                          |
| `dataTypes`    | Have one of these data types.                                     |
| `notDataTypes` | Do not have any of these data types.                              |
| `isIndex`      | Are index channels (`true`) or are not (`false`).                 |
| `virtual`      | Are virtual channels. Calculated channels are not in the results. |
| `internal`     | Are channels that Synnax uses for itself (`true`) or are not.     |
| `limit`        | Are in the first `limit` results.                                 |
| `offset`       | Come after the first `offset` results.                            |

Synnax returns only the channels that match all of the filters.

  </Fragment>

</Client.Tabs>

## Find the channels of a range

A range can give channels a different name, called an
[alias](/reference/ranges/aliases). To find channels by alias, or to read their data in
a range, see [read and write range data](/reference/ranges/data).
