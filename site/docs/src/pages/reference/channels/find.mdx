In the Console, you find a [channel](/reference/channels) to plot it or to add it to a
schematic. In a script, you retrieve a channel before you read or write its data.

## Find a channel in the Console

The [channels toolbar](/reference/channels#channels-in-the-console) lists all of the
channels in Synnax. To open it, click <Icon.Channel /> or press **C**. Drag a channel
onto a line plot or a schematic, or double-click it to add it to the open line plot.

To filter the toolbar, click <Icon.Search /> in its header and type part of a name.
Click <Icon.TreeView /> to show the results in their groups. Press **Escape** in the
field to close the search.

<Video id="client/channels/search" />

You can also find a channel from anywhere in the Console. Click <Icon.Search /> at the
top of the left bar, or press **Ctrl+P** (**Cmd+P** on macOS), to open the
[search palette](/reference/get-started/ui-overview#search-and-command-palette). Then
type part of the name. Select a result to add the channel to the open line plot, or to a
new line plot. A virtual channel opens in a log.

## Retrieve channels in code

A script gets a channel from the Core before it reads or writes its data. Retrieve
channels by name or key, by a pattern, or by a search term.

### By name or key

<Client.Tabs exclude={["console"]}>

  <Fragment slot="python">

```python
# One channel, by name or by key
tank_pressure = client.channels.retrieve("tank_pressure")
tank_pressure = client.channels.retrieve(tank_pressure.key)

# Many channels, by names or by keys
channels = client.channels.retrieve(["tank_pressure", "tank_temperature"])
channels = client.channels.retrieve([tank_pressure.key, tank_temperature.key])
```

When you pass one name or key, `retrieve` returns one channel. It raises
`sy.NotFoundError` when no channel matches, and `sy.MultipleFoundError` when more than
one channel has the name. When you pass a list, `retrieve` returns a list and leaves out
the channels that it does not find. To get one channel for any other filter, pass
`one=True`.

Pass names or keys, not both in one list. A key never changes, but a name can change.
Store keys in programs that run for a long time.

  </Fragment>

  <Fragment slot="typescript">

```typescript
// One channel, by name or by key
const tankPressure = await client.channels.retrieve("tank_pressure");
const sameChannel = await client.channels.retrieve(tankPressure.key);

// Many channels, by names or by keys
const names = ["tank_pressure", "tank_temperature"];
const byName = await client.channels.retrieve(names);
const byKey = await client.channels.retrieve([tankPressure.key, sameChannel.key]);
```

When you pass one name or key, `retrieve` returns one channel. It throws a
`NotFoundError` when no channel matches, and a `MultipleFoundError` when more than one
channel has the name. When you pass an array, `retrieve` returns an array and leaves out
the channels that it does not find. To get one channel for any other filter, pass
`one: true`.

Pass names or keys, not both in one array. A key never changes, but a name can change.
Store keys in programs that run for a long time.

  </Fragment>

</Client.Tabs>

### By pattern

A `name` filter selects channels by a pattern in their name. Set one or more operators.
A channel must match all of them. A plain name, as in the section above, always matches
exactly.

| Python             | TypeScript        | Matches names that                                                                           |
| ------------------ | ----------------- | -------------------------------------------------------------------------------------------- |
| `contains`         | `contains`        | Hold the text.                                                                               |
| `starts_with`      | `startsWith`      | Start with the text.                                                                         |
| `regex`            | `regex`           | Match the regular expression, in [Go RE2 syntax](https://github.com/google/re2/wiki/Syntax). |
| `in_`              | `in`              | Equal one of the names in the list.                                                          |
| `case_insensitive` | `caseInsensitive` | Set to true, the other operators ignore case.                                                |

A `regex` can match any part of the name, so start it with `^` to match from the start.
For example, `^tank_` matches `tank_pressure` and `tank_time`, but not
`ox_tank_pressure`.

<Client.Tabs exclude={["console"]}>

  <Fragment slot="python">

```python
import synnax as sy

# Returns list[sy.Channel]
tank_channels = client.channels.retrieve(
    where=sy.channel.Where(name=sy.filter.String(regex="^tank_"))
)
pressures = client.channels.retrieve(
    where=sy.channel.Where(
        name=sy.filter.String(contains="pressure", case_insensitive=True)
    )
)
```

  </Fragment>

  <Fragment slot="typescript">

```typescript
// Returns Channel[]
const tankChannels = await client.channels.retrieve({
  where: { name: { regex: "^tank_" } },
});
const pressures = await client.channels.retrieve({
  where: { name: { contains: "pressure", caseInsensitive: true } },
});
```

  </Fragment>

</Client.Tabs>

### By search term

Both clients can search channels by a part of their name and filter them by their
properties.

<Client.Tabs exclude={["console"]}>

  <Fragment slot="python">

```python
import synnax as sy

matches = client.channels.retrieve(search_term="pressure", limit=10)
floats = client.channels.retrieve(data_types=[sy.DataType.FLOAT32], is_index=False)
```

The filters are `search_term`, `data_types`, `not_data_types`, `is_index`, `virtual`,
`internal`, `node_key`, and `limit`. Results match all the filters. Set
`include_status=True` to attach each channel's status; a channel with no status gets
`None`.

To read past the first page, sort with `order` and pass the position of the last channel
as `after`:

```python
order = sy.channel.Order(field="name")
page = client.channels.retrieve(order=order, limit=100)
last = page[-1]
after = sy.channel.Cursor(key=last.key, name=last.name)
next_page = client.channels.retrieve(order=order, after=after, limit=100)
```

  </Fragment>

  <Fragment slot="typescript">

```typescript
import { DataType } from "@synnaxlabs/client";

// The ten best matches for "pressure"
const matches = await client.channels.retrieve({
  searchTerm: "pressure",
  limit: 10,
});

// All float32 data channels
const floats = await client.channels.retrieve({
  where: { dataType: { eq: DataType.FLOAT32 }, isIndex: { eq: false } },
});
```

| Filter       | Returns channels that                    |
| ------------ | ---------------------------------------- |
| `searchTerm` | Have a name that is similar to the term. |
| `where`      | Match the filter.                        |
| `limit`      | Are in the first `limit` results.        |
| `order`      | Sort by this field.                      |
| `after`      | Come after this position in the order.   |

A `where` filter matches the properties of a channel: `key`, `name`, `dataType`,
`isIndex`, `virtual`, `internal`, and `leaseholder`. Use `and`, `or`, and `not` to
combine filters. Synnax returns only the channels that match all of the filters.

  </Fragment>

</Client.Tabs>

## Channels in a range

A range does not hold channels. It covers the data of every channel in its time
interval. To read the data of a channel in a range, see
[read and write range data](/reference/ranges/data).
