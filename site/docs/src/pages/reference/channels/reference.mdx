This page lists the properties of a [channel](/reference/channels), the data types that
it can have, and the errors that channel operations can return.

<Divider.Divider x />

## Properties

| Property  | Console field | Python      | TypeScript | Type    | Default                    | Can change |
| --------- | ------------- | ----------- | ---------- | ------- | -------------------------- | ---------- |
| Key       | None          | `key`       | `key`      | number  | Synnax sets it             | No         |
| Name      | Name          | `name`      | `name`     | string  | Required                   | Yes        |
| Data type | Data type     | `data_type` | `dataType` | string  | Required                   | No         |
| Is index  | Is index      | `is_index`  | `isIndex`  | boolean | `false`                    | No         |
| Index     | Index         | `index`     | `index`    | number  | Required for data channels | No         |
| Virtual   | Virtual       | `virtual`   | `virtual`  | boolean | `false`                    | No         |

### Key

A number that identifies the channel. Synnax sets the key when you create the channel,
and the key never changes. Plots, schematics, and tasks refer to channels by key.

### Name

The name of the channel. It must follow the [name rules](#name-rules). To change it,
[rename the channel](/reference/channels/rename-and-delete#rename-channels).

### Data type

The type of each sample in the channel. See [data types](#data-types). An index channel
always has the `timestamp` data type. In Python, `is_index=True` sets `timestamp` for
you.

### Is index

`true` for an [index channel](/reference/channels#index-channels). An index channel
cannot be virtual.

### Index

The key of the index channel that holds the timestamps of this channel. Each data
channel needs an index, and the index must exist before you create the data channel.
Leave it unset for index, virtual, and calculated channels.

### Virtual

`true` for a [virtual channel](/reference/channels#virtual-channels). Synnax streams the
values of a virtual channel and does not store them. A calculated channel also has
`virtual` set to `true`, because Synnax does not store its values.

## Calculated channel properties

A [calculated channel](/reference/channels/calculated) has a name and the properties
below. Synnax sets its data type, its index, and its `virtual` property. You can change
all of these properties after you create the channel.

| Property   | Console field | Python       | TypeScript   | Type               | Default  |
| ---------- | ------------- | ------------ | ------------ | ------------------ | -------- |
| Expression | Expression    | `expression` | `expression` | string             | Required |
| Operations | Operation     | `operations` | `operations` | list of operations | None     |

### Operation properties

| Property      | Console field | Python          | TypeScript     | Type     | Default  |
| ------------- | ------------- | --------------- | -------------- | -------- | -------- |
| Type          | Operation     | `type`          | `type`         | string   | Required |
| Window        | Window        | `duration`      | `duration`     | TimeSpan | `0`      |
| Reset channel | Reset channel | `reset_channel` | `resetChannel` | number   | `0`      |

- **Type**: `min`, `max`, `avg`, `derivative`, or `none`.
- **Window**: The time after which `min`, `max`, or `avg` resets. `0` never resets. In
  the Console, the window is in seconds.
- **Reset channel**: The key of a `boolean` channel. `min`, `max`, or `avg` resets when
  this channel receives `true`. `0` means no reset channel.

The Console sets one operation. The client libraries accept a list, and Synnax applies
the operations in order.

## Data types

| Data type   | Size     | Arc type | Description                                                         |
| ----------- | -------- | -------- | ------------------------------------------------------------------- |
| `boolean`   | 1 byte   | `bool`   | `true` or `false`.                                                  |
| `int8`      | 1 byte   | `i8`     | Signed 8-bit integer.                                               |
| `int16`     | 2 bytes  | `i16`    | Signed 16-bit integer.                                              |
| `int32`     | 4 bytes  | `i32`    | Signed 32-bit integer.                                              |
| `int64`     | 8 bytes  | `i64`    | Signed 64-bit integer.                                              |
| `uint8`     | 1 byte   | `u8`     | Unsigned 8-bit integer.                                             |
| `uint16`    | 2 bytes  | `u16`    | Unsigned 16-bit integer.                                            |
| `uint32`    | 4 bytes  | `u32`    | Unsigned 32-bit integer.                                            |
| `uint64`    | 8 bytes  | `u64`    | Unsigned 64-bit integer.                                            |
| `float32`   | 4 bytes  | `f32`    | 32-bit floating-point number.                                       |
| `float64`   | 8 bytes  | `f64`    | 64-bit floating-point number.                                       |
| `timestamp` | 8 bytes  | `i64`    | Nanoseconds since the Unix epoch, in UTC.                           |
| `uuid`      | 16 bytes | `str`    | A [UUID](https://www.rfc-editor.org/rfc/rfc9562.html).              |
| `string`    | Variable | `str`    | UTF-8 text.                                                         |
| `json`      | Variable | `str`    | A JSON value.                                                       |
| `bytes`     | Variable | None     | Raw bytes. Arc automations and calculated channels cannot use them. |

All data types can be stored, and all can be virtual. Only `timestamp` can be the data
type of an index channel.

## Name rules

- A name contains only letters, digits, and underscores.
- A name cannot start with a digit.
- Each name is unique. Names are case-sensitive, so `tank_pressure` and `Tank_pressure`
  are two different names.

An administrator can turn off these rules on a Core with the
[`--disable-channel-name-validation`](/reference/enterprise/cli-reference#flags) flag.
Then names can have any characters, and two channels can have the same name.

## Errors

| Error message                                                             | Cause                                                                                   |
| ------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| `channel with name '<name>' already exists`                               | Another channel has this name. Select a different name.                                 |
| `channel name '<name>' contains invalid characters`                       | The name does not follow the [name rules](#name-rules).                                 |
| `non-indexed channel must have an index`                                  | A data channel has no index. Set its index, or make it virtual.                         |
| `virtual channel cannot be indexed`                                       | A virtual channel has an index, or is an index. Remove the index setting.               |
| `index channel with key <key> does not exist`                             | The index does not exist. Create the index channel first.                               |
| `channel <key> is not an index`                                           | The index setting points to a channel that is not an index channel.                     |
| `calculated channels cannot specify an index manually`                    | A calculated channel has an index setting. Remove it, because Synnax creates the index. |
| `undefined symbol: <name>`                                                | An expression uses a channel name that does not exist.                                  |
| `cannot delete channel <index> because it indexes data in channel <data>` | Data channels use this index. Delete them first, or in the same call.                   |
| `there are <n> unclosed writers/iterators accessing it`                   | A task or a script has the channel open. Stop it, then delete the channel.              |
| `NotFoundError`                                                           | No channel matches the name or key.                                                     |
| `MultipleFoundError`                                                      | A pattern matches more than one channel. Put the pattern in a list.                     |
