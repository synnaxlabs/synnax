The Synnax Console is a desktop application to visualize data, control hardware, and
manage a Synnax Core. It runs on Windows 11 and macOS Sequoia or later. To install and
start a Core, see [Set up Synnax Enterprise](/reference/enterprise).

## Connecting a Core

The login window shows a list of Cores. To add a Core, click **Add a Core**. Enter the
name, host, port, and secure setting, then click **Connect**.

To log in, select the Core in the list. Enter your **Username** and **Password**, then
click **Log in**. The root user of a new Core is `synnax` with the password `seldon`,
unless the Core started with different
[`--username` and `--password` flags](/reference/enterprise/cli-reference#start).

## Requirements

### Hardware

|             | Minimum                                             | Recommended                                          |
| ----------- | --------------------------------------------------- | ---------------------------------------------------- |
| **CPU**     | Intel Core i5 (8th gen) / AMD Ryzen 5 (3000 series) | Intel Core i7 (10th gen) / AMD Ryzen 7 (4000 series) |
| **RAM**     | 8 GB                                                | 16 GB or more                                        |
| **Storage** | 2 GB available                                      | 4 GB available (SSD recommended)                     |

### Graphics

The Console uses the GPU heavily. High-frequency plots and dense schematics need a
dedicated graphics card to run smoothly.

|             | Minimum                      | Recommended                      |
| ----------- | ---------------------------- | -------------------------------- |
| **GPU**     | NVIDIA GTX 1030 / AMD RX 550 | NVIDIA RTX 2060 / AMD RX 5600 XT |
| **VRAM**    | 2 GB                         | 6 GB or more                     |
| **DirectX** | Version 12                   | Version 12 Ultimate              |
| **OpenGL**  | Version 4.5                  | Version 4.6                      |

Integrated graphics (Intel Iris Xe, AMD Radeon Vega) work. Performance decreases with
many high-frequency streams, long time ranges, or complex schematics.

### Display

Use a display of at least 1920x1080. A 4K display is preferred for extended use.
