The service commands (`install`, `uninstall`, `stop`, `restart`, `status`, and `logs`)
are only available on Linux and NI Linux Real-Time. On Linux, run them with `sudo`. On
Windows and macOS, run the Driver in the foreground with
`synnax-driver start --standalone` and stop it with Ctrl+C.

<Divider.Divider x />

## Start

The `start` command starts the installed Driver service. With the `--standalone` flag,
it runs the Driver in the foreground, which is the only mode on Windows and macOS.

### Example usage

```bash
synnax-driver start
```

To run in the foreground instead:

```bash
synnax-driver start --standalone
```

## Stop

The `stop` command stops the Driver service. If the Driver is running in the foreground,
press Ctrl+C instead.

### Example usage

```bash
synnax-driver stop
```

<Divider.Divider x />

## Restart

The `restart` command stops and then starts the Driver service.

### Example usage

```bash
synnax-driver restart
```

<Divider.Divider x />

## Login

The `login` command saves the connection parameters for a Synnax Core. On Linux, run it
with `sudo`. If the Driver is already running, restart it to apply the new credentials.

### Example usage

```bash
synnax-driver login
```

The command prompts for the Core's connection parameters:

```
synnax-driver login
Host [localhost]: 10.0.0.45
Port [9090]: 9090
Secure (Y/N) [N]: N
Username: synnax
Password:
```

<Divider.Divider x />

## Clear

The `clear` command clears the persisted state file: the connection parameters saved by
the `login` command and the cached rack identity. The next start creates a new rack. On
Linux, run it with `sudo`.

### Example usage

```bash
synnax-driver clear
```

<Divider.Divider x />

## Status

The `status` command prints the Driver's status to the console.

### Example usage

```bash
synnax-driver status
```

<Divider.Divider x />

## Uninstall

The `uninstall` command removes the service. The binary and the `synnax` user are kept.
On Windows and macOS, delete the binary instead.

### Example usage

```bash
synnax-driver uninstall
```

<Divider.Divider x />

## Logs

The `logs` command streams the Driver's logs to the console until you press Ctrl+C.

### Example usage

```bash
synnax-driver logs
```

<Divider.Divider x />

## Version

The `version` command prints the Driver's version to the console.

### Example usage

```bash
synnax-driver version
```
