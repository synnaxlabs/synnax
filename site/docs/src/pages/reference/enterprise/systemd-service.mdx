On Linux, you can run a Synnax Core as a systemd service. This is an example service
file, usually kept at `/lib/systemd/system/synnax.service`:

```ini
[Unit]
Description = synnax

[Service]
Type = simple
User = synnax
Group = synnax
LimitNOFILE = 4096
Restart = always
RestartSec = 5s
StandardOutput = file:/home/synnax/synnax.log
StandardError = file:/home/synnax/errors.log
ExecStart = /home/synnax/synnax start --listen=localhost:9090

[Install]
WantedBy = multi-user.target
```

For the flags that `synnax start` accepts, see the
[Core CLI reference](/reference/enterprise/cli-reference#start).
