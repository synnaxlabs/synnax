A client machine must trust the CA certificate of a Synnax Core that uses a self-signed
certificate, such as one started with `--auto-cert`. By default, the Core keeps its CA
certificate at `/usr/local/synnax/certs/ca.crt`. Select your operating system.

<Fragment slot="linux">
## Linux

Copy the CA certificate from the Core. If you have SSH access to the Core, use `scp`:

```bash
scp user@core:/path/to/ca.crt /tmp/synnax-ca.crt
```

On Debian and Ubuntu, copy the certificate into the local CA directory and rebuild the
trust bundle:

```bash
sudo cp /tmp/synnax-ca.crt /usr/local/share/ca-certificates/synnax-ca.crt
sudo update-ca-certificates
```

On RHEL and Fedora, use the CA trust anchors directory:

```bash
sudo cp /tmp/synnax-ca.crt /etc/pki/ca-trust/source/anchors/synnax-ca.crt
sudo update-ca-trust
```

If you cannot change the trust store, point the Driver at the certificate file. The
Driver service and `synnax-driver login` read `/etc/synnax/driver.env`. Add this line to
the file:

```bash
GRPC_DEFAULT_SSL_ROOTS_FILE_PATH=/tmp/synnax-ca.crt
```

Add the line before you run `synnax-driver login`, because `login` checks the connection
to the Core.

</Fragment>
<Fragment slot="windows">
## Windows

Copy the CA certificate from the Core. Then install it with the `Import-Certificate`
command. You may need to open PowerShell as an administrator to run the command.

```powershell
Import-Certificate -FilePath PATH_TO_CA_CRT -CertStoreLocation Cert:\LocalMachine\Root
```

</Fragment>
<Fragment slot="macos">
## macOS

Copy the CA certificate from the Core. If you have SSH access to the Core, use `scp`:

```bash
scp user@core:/path/to/ca.crt /tmp/synnax-ca.crt
```

If you do not have SSH access, paste the certificate into a new file. Then open a new
terminal and run this command:

```bash
sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain /tmp/synnax-ca.crt
```

The Driver does not read the Keychain. Point it at the certificate file instead, in the
same shell that runs `synnax-driver`:

```bash
export GRPC_DEFAULT_SSL_ROOTS_FILE_PATH=/tmp/synnax-ca.crt
```
