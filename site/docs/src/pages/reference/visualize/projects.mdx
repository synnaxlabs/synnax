A project holds your layouts. Each project has one or more panels. A panel is an
arrangement of tabs, such as line plots, schematics, tables, and logs. The panel
selector at the top of the Console shows the panels in the current project.

Make one project for each test stand, campaign, or operator view. The Console always
works inside a project. When no project is open, the Console shows a list of projects to
open, and a button to create a new one.

## Creating and loading

### Create

Create a project from the project selector in the top-left corner of the Console, or
with the `Create project` command in the
[command palette](/reference/get-started/ui-overview#search-and-command-palette).

<Video id="console/workspaces/create" />

### Load

Load a project from the [projects toolbar](/reference/get-started/ui-overview#projects)
on the left-hand side, or from the project selector in the top-left corner.

<Video id="console/workspaces/load" />

<Divider.Divider x />

## Sharing a project

### Via file

Right-click the project in the projects toolbar and click `Export`. You can also run the
`Export current project` command in the
[command palette](/reference/get-started/ui-overview#search-and-command-palette).

<Image id="console/workspaces/export" />

The Console saves the project as a `.zip` file. The file holds the panels of the project
and the visualizations in them.

<Edition.Enterprise>

### Via link

Right-click the project in the projects toolbar and click `Copy link`. Anyone connected
to the same Core can open the project by pasting the link into a web browser.

<Image id="console/workspaces/copy-link" />

</Edition.Enterprise>

<Divider.Divider x />

## Importing a project

Run the `Import project` command and select a `.zip` file or the folder you extracted
from it. You can also drag the `.zip` file or the folder into the Console.
