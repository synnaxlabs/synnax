## Run an example

<Client.Tabs exclude={["console"]}>

  <Fragment slot="python">

Most Python examples connect with the login that `sy login` saves. Log in once, see
[Log in once with sy login](/reference/client/connect#log-in-once-with-sy-login), then
run a script:

```bash
python basic_read_write.py
```

The Arduino examples set their connection values in the script.

The control examples and the simulators import other example files. Run them as modules
from the `client/py` folder, with a simulator in a second terminal:

```bash
python -m examples.simulators.press
python -m examples.control.press.control_sequence
```

The README in each folder gives the steps.

  </Fragment>

  <Fragment slot="typescript">

The TypeScript examples connect to `localhost:9090` with the username `synnax` and the
password `seldon`. Change these values in the script to match your Core. From the
`client/ts/examples/node` folder, install the client and run a script:

```bash
npm install
node basicReadWrite.js
```

`streamRead.js` streams the samples that `streamWrite.js` writes. Run `streamWrite.js`
first, in a second terminal.

  </Fragment>

## Examples by topic

Write, read, and work with data. See [Write data](/reference/client/write-data) and
[Read data](/reference/client/read-data).

| Example                                                                                                        | Shows how to                                                   |
| -------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| [basic_read_write.py](https://github.com/synnaxlabs/synnax/blob/main/client/py/examples/basic_read_write.py)   | Create channels, write samples, read them back, and plot them. |
| [read_latest.py](https://github.com/synnaxlabs/synnax/blob/main/client/py/examples/read_latest.py)             | Read the latest samples of a channel.                          |
| [series_and_frames.py](https://github.com/synnaxlabs/synnax/blob/main/client/py/examples/series_and_frames.py) | Work with series and frames.                                   |
| [export_to_csv.py](https://github.com/synnaxlabs/synnax/blob/main/client/py/examples/export_to_csv.py)         | Export samples to a CSV file.                                  |
| [plot.py](https://github.com/synnaxlabs/synnax/blob/main/client/py/examples/plot.py)                           | Plot samples with Matplotlib.                                  |

Stream data. See [Stream data](/reference/client/stream-data). The scripts that read
live samples need `stream_write.py` to run in a second terminal.

| Example                                                                                                        | Shows how to                                            |
| -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| [stream_write.py](https://github.com/synnaxlabs/synnax/blob/main/client/py/examples/stream_write.py)           | Write live samples with a writer.                       |
| [stream_read.py](https://github.com/synnaxlabs/synnax/blob/main/client/py/examples/stream_read.py)             | Stream live samples.                                    |
| [stream_read_async.py](https://github.com/synnaxlabs/synnax/blob/main/client/py/examples/stream_read_async.py) | Stream live samples with `asyncio`.                     |
| [simulation.py](https://github.com/synnaxlabs/synnax/blob/main/client/py/examples/simulation.py)               | Write many channels and answer commands to many valves. |

| [create_range.py](https://github.com/synnaxlabs/synnax/blob/main/client/py/examples/create_range.py)               | Create a range and read its data.                                   |

| [control/abort/](https://github.com/synnaxlabs/synnax/tree/main/client/py/examples/control/abort)          | Watch for overpressure, take control, and vent the system.    |
