In this tutorial, you write a script that stores five pressure samples in a Synnax Core
and reads them back. It takes about five minutes. Each step adds code to one file:
`quick_start.py` for Python or `quick_start.ts` for TypeScript. Do not name the Python
file `synnax.py`, because that name hides the `synnax` package.

You need:

- A Core in [Synnax Enterprise](/reference/enterprise) that your computer can reach, and
  a username and password for it.
- Python 3.12 or later, or Node.js 22 or later.

## Install the client

<Client.Tabs exclude={["console"]}>

  <Fragment slot="python">

```bash
pip install synnax
```

  </Fragment>

  <Fragment slot="typescript">

The script uses top-level await, so make an ES module project:

```bash
npm init -y
npm pkg set type=module
npm install @synnaxlabs/client tsx
```

  </Fragment>

</Client.Tabs>

Install the client version that matches the major and minor version of your Core, such
as client 0.60 for Core 0.60. The client prints a warning when the versions differ.

## Connect to the Core

Replace the address and credentials with the values of your Core. For TLS and other
options, see [Connect to a Core](/reference/client/connect).

<Client.Tabs exclude={["console"]}>

  <Fragment slot="python">

```python
import synnax as sy

client = sy.Synnax(
    host="localhost",
    port=9090,
    username="synnax",
    password="seldon",
)
```

  </Fragment>

  <Fragment slot="typescript">

```typescript
import { DataType, Synnax, TimeSpan, TimeStamp } from "@synnaxlabs/client";

const client = new Synnax({
  host: "localhost",
  port: 9090,
  username: "synnax",
  password: "seldon",
});
```

  </Fragment>

</Client.Tabs>

## Create two channels

The samples go in a data channel, and their timestamps go in an index channel. For more
about channels, see [Create channels](/reference/channels/create).

<Client.Tabs exclude={["console"]}>

  <Fragment slot="python">

```python
time = client.channels.create(
    name="tank_time",
    data_type=sy.DataType.TIMESTAMP,
    is_index=True,
    retrieve_if_name_exists=True,
)
pressure = client.channels.create(
    name="tank_pressure",
    data_type=sy.DataType.FLOAT32,
    index=time.key,
    retrieve_if_name_exists=True,
)
```

  </Fragment>

  <Fragment slot="typescript">

```typescript
const time = await client.channels.create(
  { name: "tank_time", dataType: DataType.TIMESTAMP, isIndex: true },
  { retrieveIfNameExists: true },
);
const pressure = await client.channels.create(
  { name: "tank_pressure", dataType: DataType.FLOAT32, index: time.key },
  { retrieveIfNameExists: true },
);
```

  </Fragment>

</Client.Tabs>

## Write five samples

Write one sample every 100 milliseconds, starting now:

<Client.Tabs exclude={["console"]}>

  <Fragment slot="python">

```python
start = sy.TimeStamp.now()
client.write(
    start,
    {
        "tank_time": [
            start + sy.TimeSpan.MILLISECOND * 100 * i for i in range(5)
        ],
        "tank_pressure": [20.0, 20.5, 21.0, 21.5, 22.0],
    },
)
```

  </Fragment>

  <Fragment slot="typescript">

```typescript
const start = TimeStamp.now();
const step = TimeSpan.milliseconds(100);
await client.write(start, {
  tank_time: [0, 1, 2, 3, 4].map((i) => start.add(step.mult(i))),
  tank_pressure: [20.0, 20.5, 21.0, 21.5, 22.0],
});
```

  </Fragment>

</Client.Tabs>

<Divider.Divider x />

## Read the samples back

<Client.Tabs exclude={["console"]}>

  <Fragment slot="python">

```python
samples = client.read(
    sy.TimeRange(start, start + sy.TimeSpan.SECOND),
    "tank_pressure",
)
print(samples.to_numpy())
client.close()
```

  </Fragment>

  <Fragment slot="typescript">

```typescript
const samples = await client.read(
  { start, end: start.add(TimeSpan.seconds(1)) },
  "tank_pressure",
);
console.log(Array.from(samples));
await client.close();
```

  </Fragment>

</Client.Tabs>


  </Fragment>

  <Fragment slot="typescript">



  </Fragment>
