## How Synnax compares

Teams often build a test or control system from separate tools: one to acquire data, one
to store it, one for operator screens, and one for automation. Synnax does each job in
one system. Plots, schematics, sequences, and alarms all use the same channels, so
nothing needs to be wired between tools.

| Job                        | Often done with                         | In Synnax                                     |
| -------------------------- | --------------------------------------- | --------------------------------------------- |
| Acquire data from hardware | LabVIEW, NI FlexLogger, vendor software | [Hardware tasks](/reference/hardware/tasks)   |
| Store time-series data     | InfluxDB, TimescaleDB, a historian      | [Channels](/reference/channels)               |
| Plot live and past data    | Grafana, LabVIEW, Excel                 | [Line plots](/reference/visualize/line-plots) |
| Build operator screens     | Ignition, LabVIEW front panels          | [Schematics](/reference/visualize/schematics) |
| Automate sequences         | LabVIEW, PLC logic, Python scripts      | [Arc](/reference/control/arc)                 |
| Raise alarms               | SCADA alarm systems                     | [Alarms](/reference/alarms)                   |
| Organize test runs         | Folders, file names, spreadsheets       | [Ranges](/reference/ranges)                   |
