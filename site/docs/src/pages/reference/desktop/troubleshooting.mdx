Synnax Desktop starts Synnax when the app opens and stops it when the app closes. To
find a problem, start with the diagnostics dialog and the logs, then look for your
problem under [common problems](#common-problems). Each command runs from the
[command palette](/reference/get-started/ui-overview#search-and-command-palette).

## Diagnostics

To open the diagnostics dialog, run the "Open diagnostics" command. The dialog shows the
state of Synnax, such as **Running** or **Stopped unexpectedly**, and:

- **Version** -> the version of Synnax Desktop.
- **Running since** -> when Synnax became ready. Shown only while Synnax runs.
- **Starts** -> the number of times Synnax started since the app opened.
- **Last problem** -> the last problem, if there was one.
- **Data** -> the size and location of the data folder.
- The end of the log, updated every 2 seconds.

The dialog has the buttons **Erase all data**, **Show data folder**, **Show logs**,
**Export**, and **Restart**.

### Export diagnostics for support

1. In the diagnostics dialog, click **Export**.
2. Select where to save the file.

Synnax Desktop saves a zip file named `synnax-diagnostics-<date>.zip`. It holds a
summary of the app, the computer, and the recent starts, and all log files. It holds no
recorded data and no passwords. Send this file to the person who supports you.

## Logs

Synnax writes its log to `core.log` in the log folder. To open the folder, run the "Show
logs" command.

| Operating system | Log folder                                   |
| ---------------- | -------------------------------------------- |
| macOS            | `~/Library/Logs/com.synnaxlabs.desktop`      |
| Windows          | `%LOCALAPPDATA%\com.synnaxlabs.desktop\logs` |

## Common problems

### The top bar shows "Reconnecting"

The Console cannot reach Synnax. Most often, Synnax stopped and Synnax Desktop is
starting it again, and the indicator goes away in a few seconds. If it stays, run "Open
diagnostics".

### Synnax Desktop shows "Synnax stopped unexpectedly"

Synnax failed five times in a row, so Synnax Desktop stopped trying to start it. A
failure is a crash, a start that takes more than 60 seconds, or three failed health
checks in a row. The last problem shows under the heading.

1. Click **Restart** to try again.
2. If Synnax stops again, click **Diagnostics** and
   [export diagnostics](#export-diagnostics-for-support) for support.

### The app shows "Starting Synnax..." for more than a minute

After 60 seconds, Synnax Desktop counts the start as a failure and tries again. If the
start keeps failing, the app shows "Synnax stopped unexpectedly".

### Live data or tasks stopped

Run the "Restart Synnax" command, then click **Restart** to confirm. Running tasks and
live data stop for a few seconds, then start again. If a task still does not run, see
[Troubleshoot hardware](/reference/hardware/troubleshooting).

### I want to start again with no data

Run the "Erase all data" command. To learn what it deletes, see
[erase all data](/reference/desktop/data#erase-all-data).
