Synnax Desktop keeps its data in one folder for each user account on the computer:

| Operating system | Data folder                                                 |
| ---------------- | ----------------------------------------------------------- |
| macOS            | `~/Library/Application Support/com.synnaxlabs.desktop/core` |
| Windows          | `%LOCALAPPDATA%\com.synnaxlabs.desktop\core`                |

The folder holds your channels, recorded data, ranges, and projects. To open it, run the
"Show data folder" command. Do not change the files in the folder while Synnax Desktop
runs.

<Divider.Divider x />

## Metadata backups

Before a new version of Synnax Desktop first runs on your data, it copies your channels,
ranges, and projects to the `backups` folder next to the data folder. It keeps the three
newest copies. The copies hold no recorded data. Synnax Desktop has no way to restore a
copy.

<Divider.Divider x />

## Erase all data

<Note.Note variant="error">
  Erase all data cannot be undone. It deletes every channel, all recorded data, every
  project, and all metadata backups.
</Note.Note>

1. Run the "Erase all data" command, or select **Erase all data** in the diagnostics
   dialog.
2. Hold the **Erase all data** button for one second to confirm.

Synnax Desktop deletes the data, then closes and opens again with no data. The logs and
your app settings stay. If the erase fails, Synnax stays stopped: click **Restart** in
the diagnostics dialog.
