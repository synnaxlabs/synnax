[Metadata](/reference/ranges#metadata) stores key and value pairs on a range, such as a
part number or a test configuration. Keys and values are text. In code, cast each value
to the type that you need. [Labels](/reference/ranges#labels) sort ranges into groups
that you can filter by.

## Set metadata

<Client.Tabs exclude={["cpp"]}>

  <Fragment slot="console">

{/* prettier-ignore-start */}

In the metadata section of the [range overview](/reference/ranges/find#range-overview), click create
(<Icon.Add />). Enter a key and a value, then click the check (<Icon.Check />). To
change a value, click it and type the new value.

{/* prettier-ignore-end */}

<Video id="client/ranges/set-metadata" />

  </Fragment>

  <Fragment slot="python">

```python
my_range = client.ranges.retrieve(name="My Range")

# Set a single key/value pair
my_range.meta_data.set("part_number", "12345")

# Another way to set a single key/value pair
my_range.meta_data["part_number"] = "12345"

# Set multiple key/value pairs
my_range.meta_data.set({
    "part_number": "12345",
    "test_configuration": "Test 1",
    "test_result": "123.45",
})
```

  </Fragment>

  <Fragment slot="typescript">

```typescript
const myRange = await client.ranges.retrieve("My Range");

// Set a single key/value pair
await myRange.kv.set("part_number", "12345");

// TypeScript only supports the set() method
// (no bracket syntax)

// Set multiple key/value pairs
await myRange.kv.set({
  part_number: "12345",
  test_configuration: "Test 1",
  test_result: "123.45",
});
```

  </Fragment>
</Client.Tabs>

## Get metadata

<Client.Tabs exclude={["cpp"]}>

  <Fragment slot="console">

The metadata section of the [range overview](/reference/ranges/find#range-overview)
lists every key and value. Click the copy button beside a value to copy it.

  </Fragment>

  <Fragment slot="python">

```python
my_range = client.ranges.retrieve(name="My Range")

# Retrieve a single key
part_number = my_range.meta_data["part_number"] # Or use .get("key")

# Retrieve multiple keys
metadata = my_range.meta_data.get(["part_number", "test_configuration"])

# List all metadata
all_metadata = my_range.meta_data.get([])
```

  </Fragment>

  <Fragment slot="typescript">

```typescript
const myRange = await client.ranges.retrieve("My Range");

// Retrieve a single key
const partNumber = await myRange.kv.get("part_number");

// Retrieve multiple keys
const metadata = await myRange.kv.get(["part_number", "test_configuration"]);

// List all metadata
const allMetadata = await myRange.kv.list();
```

  </Fragment>
</Client.Tabs>

## Delete metadata

<Client.Tabs exclude={["cpp"]}>

  <Fragment slot="console">

{/* prettier-ignore-start */}

In the metadata section of the [range overview](/reference/ranges/find#range-overview), click delete
(<Icon.Delete />) beside the key.

{/* prettier-ignore-end */}

  </Fragment>

  <Fragment slot="python">

```python
my_range = client.ranges.retrieve(name="My Range")

# Delete a single key
del my_range.meta_data["part_number"] # Or use .delete("key")

# Delete multiple keys
my_range.meta_data.delete(["part_number", "test_configuration"])
```

  </Fragment>

  <Fragment slot="typescript">

```typescript
const myRange = await client.ranges.retrieve("My Range");

// Delete a single key
await myRange.kv.delete("part_number");

// Delete multiple keys
await myRange.kv.delete(["part_number", "test_configuration"]);
```

  </Fragment>
</Client.Tabs>

## Labels

<Client.Tabs exclude={["cpp"]}>

  <Fragment slot="console">

Select labels in the create dialog or in the
[range overview](/reference/ranges/find#range-overview). To make a new label, select
`New label` at the bottom of the label list. To change your labels, run the
`Edit labels` command from the search and command palette.

<Video id="client/ranges/labels" />

  </Fragment>

  <Fragment slot="python">

```python
my_range = client.ranges.retrieve(name="My Range")

# List the labels on the range
for label in my_range.labels:
    print(label.name)
```

<Note.Note variant="info">Labels are read-only in the Python client.</Note.Note>

  </Fragment>

  <Fragment slot="typescript">

```typescript
const myRange = await client.ranges.retrieve("My Range");

// Create a label
const label = await client.labels.create({ name: "Hotfire", color: "#FF0000" });

// Add the label to the range
await myRange.addLabel(label.key);

// List the labels on the range
const labels = await myRange.retrieveLabels();

// Remove the label from the range
await myRange.removeLabel(label.key);
```

  </Fragment>
</Client.Tabs>
