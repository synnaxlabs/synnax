Rename a [range](/reference/ranges), change its times or its stage, or delete it. To
change labels and metadata, see [metadata and labels](/reference/ranges/metadata).

<Divider.Divider x />

## Rename a range

<Client.Tabs exclude={["cpp"]}>

  <Fragment slot="console">

Right-click the range in the ranges toolbar or the range explorer and select **Rename**.
You can also click the name on the
[range overview](/reference/ranges/find#range-overview).

  </Fragment>

  <Fragment slot="python">

The Python client has no rename method. Update the range with its key, as the next
section shows.

  </Fragment>

  <Fragment slot="typescript">

```typescript
await client.ranges.rename(myRange.key, "My Updated Range");
```

  </Fragment>
</Client.Tabs>

<Divider.Divider x />

## Change the times or the stage

<Client.Tabs exclude={["cpp"]}>

  <Fragment slot="console">

On the [range overview](/reference/ranges/find#range-overview), click the start or end
time on the timeline and change it. To start, complete, or reopen the range, click its
stage. Each stage change sets the start or end time. See
[stages](/reference/ranges/reference#stages).

The Console cannot change the color or the parent of a range.

  </Fragment>

  <Fragment slot="python">

Call `client.ranges.create` with the `key` of the range:

```python
from datetime import datetime

import synnax as sy

my_range = client.ranges.retrieve(name="My Range")
client.ranges.create(
    key=my_range.key,
    name="My Updated Range",
    time_range=sy.TimeRange(
        start=sy.TimeStamp(datetime(2023, 2, 12, 13, 0)),
        end=sy.TimeStamp(datetime(2023, 2, 12, 15, 0)),
    ),
    color="#00FF00",
)
```

  </Fragment>

  <Fragment slot="typescript">

Call `client.ranges.create` with the `key` of the range:

```typescript
import { TimeRange, TimeStamp } from "@synnaxlabs/client";

const myRange = await client.ranges.retrieve("My Range");
await client.ranges.create({
  key: myRange.key,
  name: "My Updated Range",
  timeRange: new TimeRange(
    new TimeStamp("2023-02-12 13:00:00"),
    new TimeStamp("2023-02-12 15:00:00"),
  ),
  color: "#00FF00",
});
```

  </Fragment>
</Client.Tabs>

<Note.Note variant="warning" className="compact">
  An update in code replaces the name, the time range, and the color. Leave out the
  color and the range loses it. Labels are only added, and the parent stays when you
  leave it out. If no range has the key, Synnax creates a new range with that key.
</Note.Note>

## Delete a range

Deleting a range also deletes its child ranges. It does not delete the data of the
channels in the range, and it does not delete its
[snapshots](/reference/ranges/snapshots).

<Client.Tabs exclude={["cpp"]}>

  <Fragment slot="console">

Right-click the range in the ranges toolbar or the range explorer and select **Delete**,
then confirm.

<Image id="client/ranges/delete" />

  </Fragment>

  <Fragment slot="python">

```python
client.ranges.delete(my_range.key)
client.ranges.delete([my_range.key, my_other_range.key])
```

A key that matches no range is ignored.

  </Fragment>

  <Fragment slot="typescript">

```typescript
await client.ranges.delete(myRange.key);
await client.ranges.delete([myRange.key, myOtherRange.key]);
```

  </Fragment>
</Client.Tabs>
