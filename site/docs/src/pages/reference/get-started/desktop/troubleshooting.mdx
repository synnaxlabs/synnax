Synnax Desktop starts Synnax when the app opens and stops it when the app closes. If
something goes wrong, use the commands below from the
[command palette](/reference/get-started/ui-overview#search-and-command-palette).

<Divider.Divider x />

## Restart Synnax

If Synnax stops unexpectedly, Synnax Desktop starts it again automatically. While it
restarts, the top bar shows "Reconnecting", and live data stops for a short time. Your
workspace stays open.

If Synnax stops five times in a row, Synnax Desktop stops trying. It shows "Synnax
stopped unexpectedly" with two buttons: **Restart** and **Diagnostics**.

To restart Synnax yourself, run the "Restart Synnax" command. Running tasks and live
data stop for a few seconds. No saved data is lost.

<Divider.Divider x />

## Logs

Synnax writes its log to `core.log` in the log folder. To open the folder, run the "Show
logs" command.

| Operating system | Log folder                                   |
| ---------------- | -------------------------------------------- |
| macOS            | `~/Library/Logs/com.synnaxlabs.desktop`      |
| Windows          | `%LOCALAPPDATA%\com.synnaxlabs.desktop\logs` |

<Divider.Divider x />

## Diagnostics

The diagnostics dialog helps you, or the person who supports you, find a problem. To
open it, run the "Open diagnostics" command. The dialog shows:

- The state of Synnax, such as **Running** or **Stopped unexpectedly**.
- The version of Synnax Desktop.
- The time Synnax started and the number of starts in this session.
- The last problem, if there was one.
- The size and location of the data folder.
- The end of the log.

The dialog has buttons to show the data folder, show the logs, restart Synnax, and erase
all data.

### Export diagnostics for support

Select **Export** in the diagnostics dialog, then select where to save the file. Synnax
Desktop writes a zip file with a summary and every file of the log folder. Send this
file to the person who supports you.
