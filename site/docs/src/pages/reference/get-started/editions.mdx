Synnax comes in two editions. Synnax Desktop is one free app that runs on your computer,
with nothing to set up. Synnax Enterprise is a Synnax Core that your team runs on its
own servers, and many people, scripts, and Drivers connect to it.

<Divider.Divider x />

## Choose an edition

Use **Synnax Desktop** when one person works on one computer. For example, an engineer
at a bench connects a LabJack or an NI device, records data, and plots it. Synnax
Desktop is also the fastest way to try Synnax.

Use **Synnax Enterprise** when a team shares one system. Choose Enterprise when you:

- Have more than one person who needs the same data.
- Connect hardware on other computers, such as a second PC or an NI CompactRIO.
- Write Python or TypeScript code that reads, writes, or controls data.
- Run Synnax on Linux or on a server.
- Need users, roles, and permissions.

## Compare the editions

The two editions share most capabilities. The table shows where they differ.

| Capability                            | Synnax Desktop                       | Synnax Enterprise                         |
| ------------------------------------- | ------------------------------------ | ----------------------------------------- |
| Operating systems                     | macOS (Apple silicon), Windows (x64) | Linux, macOS, Windows, Docker             |
| Channels and calculated channels      | Yes                                  | Yes                                       |
| Ranges                                | Yes                                  | Yes                                       |
| Projects and visualizations           | Yes                                  | Yes                                       |
| Devices and tasks                     | Yes                                  | Yes                                       |
| EtherCAT, Modbus, OPC UA, HTTP        | Yes                                  | Yes                                       |
| LabJack devices                       | Yes                                  | Windows and macOS                         |
| NI devices                            | Windows only                         | Windows, Linux, NI Linux Real-Time        |
| Arc automations                       | Yes                                  | Yes                                       |
| Statuses and alarms                   | Yes                                  | Yes                                       |
| Import and export                     | Yes                                  | Yes                                       |
| Driver on the same computer           | Yes, built in                        | Yes                                       |
| Drivers on other computers            | No                                   | Yes                                       |
| Access from other computers           | No                                   | Yes                                       |
| Python and TypeScript clients         | No                                   | Yes                                       |
| Console in a web browser              | No                                   | Yes                                       |
| Users and roles                       | No                                   | Yes                                       |
| Copy link to a resource               | No                                   | Yes                                       |
| TLS certificates                      | No                                   | Yes                                       |
| Automatic start, restart, diagnostics | Yes                                  | No, your team runs the Core               |
| Metadata backup before an update      | Yes                                  | No                                        |
| Updates                               | In the app, for all parts            | Console in the app; the rest by your team |
| Price                                 | Free                                 | Contact Synnax Labs                       |

## Get an edition

### Synnax Desktop

Synnax Desktop is free. To download it, see
[Install Synnax Desktop](/reference/get-started/install-desktop).

### Synnax Enterprise

To get Synnax Enterprise, contact [Synnax Labs](https://www.synnaxlabs.com). To install
a Core and connect to it, see [Set up Synnax Enterprise](/reference/enterprise).
