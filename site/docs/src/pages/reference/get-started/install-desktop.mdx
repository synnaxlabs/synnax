Synnax Desktop is one free app that connects to your hardware, records and shows its
data, and controls it. It includes the Synnax Console, a Synnax Core, and a Synnax
Driver. You install it once, with nothing to run from a terminal.

<Note.Note variant="info">
  Looking for the Enterprise install guide? See [Set up Synnax
  Enterprise](/reference/enterprise). Not sure which edition you need? See [Synnax
  editions](/reference/get-started/editions).
</Note.Note>

<Divider.Divider x />

## Requirements

| Operating system | Processor             |
| ---------------- | --------------------- |
| macOS            | Apple silicon (arm64) |
| Windows          | x64                   |

There is no Synnax Desktop build for Linux or for Intel Macs. To run Synnax on Linux,
use [Synnax Enterprise](/reference/enterprise). For the CPU, memory, and graphics that
Synnax Desktop needs, see
[Console hardware](/reference/enterprise/requirements#console-hardware).

NI devices work with Synnax Desktop only on Windows, because NI-DAQmx does not support
macOS. For more information, see [NI devices](/reference/hardware/ni/configure-device).

## Install

### macOS

1. Open the downloaded `.dmg` file.
2. Drag Synnax Desktop into the Applications folder.
3. Open Synnax Desktop from the Applications folder.

### Windows

1. Open the downloaded `-setup.exe` file.
2. Follow the steps of the installer.
3. Open Synnax Desktop from the Start menu.

<Divider.Divider x />

## First launch

1. Synnax Desktop shows "Starting Synnax..." and then "Preparing your workspace...".
2. On the "Log in to continue" screen, select **Log in**. Your web browser opens. Log in
   to your Synnax account, and Synnax Desktop continues on its own.
3. Synnax Desktop shows the list of projects. Select **Sample project** to open a
   simulated tank system, or select **New project** to start with an empty project.

Each user account on the computer has its own Synnax Desktop data. Your channels,
recorded data, and projects stay on your computer.

When a new version is ready, the top bar shows **Update available**. Select it, then
select **Update and restart**.
