Synnax Desktop is one app that collects, stores, and shows data from your hardware. It
includes the Synnax Console, a private database, and a Synnax Driver. You install it
once and use it with nothing to run from a terminal. Synnax Desktop is free.

<Divider.Divider x />

## Requirements

| Operating system | Processor             |
| ---------------- | --------------------- |
| macOS            | Apple silicon (arm64) |
| Windows          | x64                   |

There is no Synnax Desktop build for Linux or for Intel Macs. To run Synnax on Linux,
use [Synnax Enterprise](/reference/enterprise).

NI devices work with Synnax Desktop only on Windows, because NI-DAQmx does not support
macOS. For more information, see [NI devices](/reference/hardware/ni/configure-device).

## Install

### macOS

1. Open the downloaded `.dmg` file.
2. Drag Synnax Desktop into the Applications folder.
3. Open Synnax Desktop from the Applications folder.

### Windows

1. Open the downloaded `-setup.exe` file.
2. Follow the steps of the installer.
3. Open Synnax Desktop from the Start menu.

<Divider.Divider x />

## First launch

When Synnax Desktop opens, it shows "Starting Synnax..." while Synnax starts. Then it
shows the project selector. Select **New project** to create a project, or open one.
Synnax saves your visualizations and layout in the project. For more information, see
[projects](/reference/visualize/projects).

Each user account on the computer has its own Synnax Desktop data. All of the data stays
on your computer.
