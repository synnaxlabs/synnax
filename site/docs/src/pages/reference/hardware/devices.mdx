A device is one piece of hardware or one server that the Driver reads from or writes to,
such as an NI module, a LabJack, a PLC, or an OPC UA server. Each
[task](/reference/hardware/tasks) reads from or writes to devices.

<Divider.Divider x />

## How devices get into Synnax

The Driver finds NI, LabJack, and EtherCAT hardware by itself. Within a few seconds of
you plugging in a device, the Console shows the notification "New \<model\> connected"
with a **Configure** button. A LabJack on the network can take about a minute to appear.
Configure gives the device a name and an identifier. The Driver also finds simulated NI
devices that you create in NI MAX, so you can try Synnax without hardware. It skips
CompactRIO controllers.

You connect Modbus, OPC UA, and HTTP servers yourself. Run the "Connect Modbus server",
"Connect OPC UA server", or "Connect HTTP server" command, then enter the address of the
server. The **Connect from** field picks the Driver that talks to the server.

Each setup page shows the steps:
[EtherCAT](/reference/hardware/ethercat/configure-device),
[HTTP](/reference/hardware/http/connect-server),
[LabJack](/reference/hardware/labjack/configure-device),
[Modbus](/reference/hardware/modbus/connect-server),
[National Instruments](/reference/hardware/ni/configure-device), and
[OPC UA](/reference/hardware/opc-ua/connect-server).

## Identifiers

NI, LabJack, and EtherCAT devices have an identifier, such as `dev1`. The identifier
starts the default names of the
[channels that tasks create](/reference/channels#channels-that-tasks-create) for the
device, such as `dev1_ai_0`. A name that you enter for a channel replaces the default.

An identifier has 2 to 12 characters. It starts with a letter, and then holds only
letters, numbers, and underscores. The Console suggests short identifiers from the
device name.

**Change identifier** changes the prefix of channels that tasks create later. Existing
channels keep their names.

## Devices toolbar

To open the devices toolbar, click <Icon.Device /> in the left bar or press `D`. The
toolbar shows each Driver, with its devices under it. NI modules show under their
chassis. Each device shows its vendor logo, its name, its location, and a status dot.

| Driver                     | What it is                                                     |
| -------------------------- | -------------------------------------------------------------- |
| **Node 1 Embedded Driver** | The Driver in Synnax Desktop or in a Synnax Core               |
| **Node 1**                 | Runs Arc automations and PagerDuty alert tasks inside the Core |
| The name of a computer     | A standalone Driver on that computer                           |

## Statuses

Hover over a status dot to see its message.

| Message                                        | Shown on                         | Meaning                                                   |
| ---------------------------------------------- | -------------------------------- | --------------------------------------------------------- |
| Driver is running                              | Driver                           | The Driver is connected to the Core.                      |
| Synnax Driver on \<name\> not running          | Driver, its devices and tasks    | The Core has not heard from the Driver for a few seconds. |
| Device present                                 | NI and LabJack devices           | The Driver found the device.                              |
| Device connected                               | Modbus and HTTP devices          | The Driver reached the server.                            |
| Server connected                               | OPC UA devices                   | The Driver reached the server.                            |
| Failed to reach device, Failed to reach server | Modbus, OPC UA, and HTTP devices | The Driver cannot connect to the server.                  |
| HTTP \<code\>, Health check validation failed  | HTTP devices                     | The server answered, but the health check failed.         |
| Discovered (\<n\> inputs, \<m\> outputs)       | EtherCAT devices                 | The Driver found the module on the network.               |
| Device disabled, Device enabled                | EtherCAT devices                 | You turned the module off or on for tasks.                |
| Device disconnected                            | Found devices                    | The Driver no longer finds the device.                    |
| Device status unknown                          | Any device                       | The device has no status yet.                             |

## Device menu

Right-click a device in the devices toolbar to open its menu.

| Item                                        | What it does                                                                                   |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Rename**                                  | Changes the device name.                                                                       |
| **Configure**                               | Names a new NI, LabJack, or EtherCAT device and sets its identifier.                           |
| **Change identifier**                       | Changes the identifier of a configured NI, LabJack, or EtherCAT device.                        |
| **Edit connection**                         | Changes the address and settings of a Modbus, OPC UA, or HTTP server.                          |
| **Disable**, **Enable**                     | Turns an [EtherCAT module](/reference/hardware/ethercat/configure-device) off or on for tasks. |
| **Create read task**, **Create write task** | Creates a task for the device. NI devices have one item for each NI task type.                 |
| **Copy properties**                         | Copies the device properties to the clipboard as JSON.                                         |
| **Delete**                                  | Removes the device. The Driver adds found hardware back as a new device at its next scan.      |

Creating a task for a device that is not configured opens **Configure** first.

Right-click a Driver to open its menu. **Create Arc automation** creates an
[Arc automation](/reference/control/arc) on that Driver. **Toggle NI device scanner**
turns the search for NI hardware off or on.
