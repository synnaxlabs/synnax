The Synnax Driver connects to [Modbus TCP/IP](https://modbus.org) servers such as PLCs,
variable-frequency drives, power meters, and industrial I/O modules.

<Note.Note variant="warning" className="compact">
  Modbus RTU and Modbus ASCII (serial) are not supported.
</Note.Note>

<Divider.Divider x />

## Prerequisites

Before you connect to a Modbus TCP server, make sure that you have:

1. [Synnax Desktop](/reference/) installed on a computer that can reach your Modbus
   server over the network.
2. A Modbus TCP server on your network.

<Edition.Enterprise>

With Synnax Enterprise, you need a [Synnax Core](/reference/enterprise) and a Synnax
Driver that can reach your Modbus server. A Core runs an embedded Driver on its own
machine. For a different machine,
[install a standalone Driver](/reference/enterprise/driver/install). Install the
[Synnax Console](/reference/enterprise/console) on your computer.

</Edition.Enterprise>

## Configuration parameters reference

| Parameter    | Type    | Required | Default | Description                                                                                  |
| ------------ | ------- | -------- | ------- | -------------------------------------------------------------------------------------------- |
| `name`       | string  | Yes      | -       | Human-readable server name for identification in Console                                     |
| `rack`       | integer | No       | -       | Synnax Driver (rack) key that will connect to the Modbus server                              |
| `host`       | string  | Yes      | -       | IP address or hostname of the Modbus server (e.g., `192.168.1.100` or `localhost`)           |
| `port`       | integer | Yes      | -       | TCP port number for the Modbus server (standard Modbus port is 502)                          |
| `swap_bytes` | boolean | No       | `false` | Swap byte order within 16-bit words for endianness handling (applies to register types only) |
| `swap_words` | boolean | No       | `false` | Swap word order for 32-bit and 64-bit values (applies to multi-register data types only)     |

<Text.Text slot="summary" level="p"><Icon.Connect /> Connect to Modbus Server</Text.Text>

```python
import synnax as sy
from synnax import modbus

# Initialize Synnax client
client = sy.Synnax()

# Retrieve the embedded rack
rack = client.racks.retrieve_embedded_rack()

# Create the Modbus device
device = modbus.Device(
    host="192.168.1.100",
    port=502,
    name="My Modbus Server",
    location="192.168.1.100:502",
    rack=rack.key,
    swap_bytes=False,
    swap_words=False,
)

# Create the device in Synnax
device = client.devices.create(device)

# Or retrieve by location
device = client.devices.retrieve(location="192.168.1.100:502")

# Or retrieve by name
device = client.devices.retrieve(name="My Modbus Server")

print(f"Connected to Modbus server: {device.name}")
```

<Text.Text slot="summary" level="p"><Icon.Close /> Disconnect server</Text.Text>

```python
import synnax as sy

# Initialize Synnax client
client = sy.Synnax()

# Retrieve the device by name
device = client.devices.retrieve(
    name="My Modbus Server",
    ignore_not_found=True
)

if device is not None:
    # Delete the server
    client.devices.delete([device.key])
    print(f"Disconnected Modbus server: {device.name}")
else:
    print("Server not found")
```
