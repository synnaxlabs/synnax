An EtherCAT read task reads the input PDOs of one or more modules on one network into
channels. For example, it can record the two analog inputs of an EL3102 module at 1 kHz.

Before you start, you need
[configured modules](/reference/hardware/ethercat/configure-device).

<Divider.Divider x />

## PDO channels

Each channel reads one input PDO. A channel has one of two modes:

- **Automatic (PDO)** -> select the PDO by its name. Use this mode only when the name is
  unique on the module. Many modules repeat a name for each channel, such as `Value` on
  an EL3102. For a repeated name, automatic mode always reads the first PDO.
- **Manual (address)** -> enter the CoE address of the PDO: its **Index (hex)**,
  **Subindex**, **Bit length**, and **Data type**. Use this mode for repeated names.
  Copy the address from the PDOs in the
  [device properties](/reference/hardware/ethercat/configure-device#device-properties).
  They come from the scan and depend on the revision of the module. For example, an
  EL3102 can show its inputs at `0x3101:02` and `0x3102:02`, 16 bits, `int16`.

All modules in a task must be on the same port. The **Sample rate** sets how often the
task takes a sample from the network. The timestamps come from the computer clock. See
[how the Driver runs a network](/reference/hardware/ethercat/configure-device#how-the-driver-runs-a-network)
and [timing](/reference/hardware/tasks#timing).

## Create an EtherCAT read task

<Client.Tabs>
  <Fragment slot="console">

1. In the devices toolbar, right-click a module and select **Create read task**.
2. Set **Sample rate** and **Stream rate**.
3. Click **Add channel**, then select the module in **Slave device**.
4. Select a **Mode**, then select the **PDO** or enter its address.
5. Click <Icon.Play /> (**Start**).

The Console creates the channels. For a module with the identifier `ai1`, a channel for
the PDO at `0x3101:02` is `ai1_0x3101_2`, with the index channel `ai1_time`.

Starting a task restarts the network on that port. Other tasks on the port pause for a
moment.

Python does not create channels. Create them first.

```python
import synnax as sy
from synnax import ethercat

module = client.devices.retrieve(key="<module key>")
time = client.channels.create(
    name="ai1_time", is_index=True, data_type=sy.DataType.TIMESTAMP
)
ch1 = client.channels.create(
    name="ai1_ch1", index=time.key, data_type=sy.DataType.INT16
)
ch2 = client.channels.create(
    name="ai1_ch2", index=time.key, data_type=sy.DataType.INT16
)

task = ethercat.ReadTask(
    name="Analog inputs",
    sample_rate=1000,
    stream_rate=25,
    channels=[
        ethercat.ManualReadChannel(
            device=module.key,
            index=0x3101,
            sub_index=0x02,
            bit_length=16,
            data_type="int16",
            channel=ch1.key,
        ),
        ethercat.ManualReadChannel(
            device=module.key,
            index=0x3102,
            sub_index=0x02,
            bit_length=16,
            data_type="int16",
            channel=ch2.key,
        ),
    ],
)
client.tasks.configure(task)
task.start()
```

For a PDO with a unique name, use
`ethercat.AutomaticReadChannel(device=module.key, pdo="<name>", channel=...)`.

  <Fragment slot="typescript">

TypeScript does not create channels. Create them first.

```typescript
import { ethercat } from "@synnaxlabs/client";

const module = await client.devices.retrieve({ key: "<module key>" });
const time = await client.channels.create({
  name: "ai1_time",
  isIndex: true,
  dataType: "timestamp",
});
const ch1 = await client.channels.create({
  name: "ai1_ch1",
  index: time.key,
  dataType: "int16",
});

const task = await client.tasks.create({
  name: "Analog inputs",
  rack: module.rack,
  type: "ethercat_read",
  config: ethercat.readConfigZ.parse({
    sampleRate: 1000,
    streamRate: 25,
    channels: [
      {
        type: "manual",
        device: module.key,
        index: 0x3101,
        subIndex: 0x02,
        bitLength: 16,
        dataType: "int16",
        channel: ch1.key,
      },
    ],
  }),
});
await task.start();
```

## Task options

| Console label | Python field           | Default | Notes                                                     |
| ------------- | ---------------------- | ------- | --------------------------------------------------------- |
| Sample rate   | `sample_rate`          | 10 Hz   | Must be a whole multiple of the stream rate.              |
| Stream rate   | `stream_rate`          | 5 Hz    | See [read tasks](/reference/hardware/tasks#read-tasks).   |
| Data saving   | `data_saving_disabled` | On      | See [data saving](/reference/hardware/tasks#data-saving). |
| Auto start    | `auto_start`           | Off     | Starts the task each time the Driver starts.              |

## Channel reference

Each channel has a `device`, the key of the module (**Slave device**), and a `channel`,
the Synnax channel that records the value. Each table shows the Console label of a
setting, with its Python field under it.

<Channel.Types>

<Channel.Type
  name="Automatic (PDO)"
  type="automatic"
  python="AutomaticReadChannel"
>

Reads a PDO entry by its name.

| Setting                  | Default | Notes                                     |
| ------------------------ | ------- | ----------------------------------------- |
| PDO <small>`pdo`</small> |         | The PDO name, from the device properties. |

</Channel.Type>

<Channel.Type
  name="Manual (address)"
  type="manual"
  python="ManualReadChannel"
>

Reads a PDO entry by its CoE address.

| Setting                                | Default  | Notes                                      |
| -------------------------------------- | -------- | ------------------------------------------ |
| Index (hex) <small>`index`</small>     | `0`      | The CoE index, such as `0x6000`.           |
| Subindex <small>`sub_index`</small>    | `0`      | The CoE subindex, from 0 to 255.           |
| Bit length <small>`bit_length`</small> | `16`     | The size of the value, from 1 to 255 bits. |
| Data type <small>`data_type`</small>   | `uint16` | The data type of the channel.              |

</Channel.Type>

## Troubleshooting

### Two channels show the same values

Both channels use automatic mode with a repeated PDO name, so both read the first PDO.
Change the channels to manual mode with the address of each PDO.

### "All slaves must be on the same network"

The task uses modules on two ports. Create one task for each port.

### "sample_rate must be divisible by stream_rate"

Set a sample rate that is a whole multiple of the stream rate, such as 1000 Hz and 25
Hz.

### "PDO ... not found in slave"

The module has no PDO with that name. Select a PDO from the list again, or use manual
mode.

For other problems, see
[Configure an EtherCAT device](/reference/hardware/ethercat/configure-device#troubleshooting)
and [Troubleshoot hardware](/reference/hardware/troubleshooting).
