An NI counter read task reads the counter inputs of NI devices into channels. A counter
measures digital pulses: their frequency, their count, their width, or the position and
speed of an encoder. For example, it can record the speed of a flow meter on `ctr0` of a
USB-6343.

Before you start, you need
[configured devices](/reference/hardware/ni/configure-device).

<Divider.Divider x />

## Counters and timing

Each channel reads one counter, set by its **Port**: port 0 is `ctr0`. The pulses come
in on a PFI terminal. Set **Input terminal** to choose the terminal, or leave it empty
to use the default terminal of the counter. The device manual lists the counters and
their terminals.

The Driver reads the counters on the computer clock, at the **Sample rate**. See
[timing](/reference/hardware/tasks#timing).

## Create an NI counter read task

<Client.Tabs>
  <Fragment slot="console">

1. In the devices toolbar, right-click a device and select **Create counter read task**.
2. Set **Sample rate** and **Stream rate**.
3. Click **Add channel**. In **Source**, select the **Device** and the **Port**.
4. In **Signal**, select the **Channel type**, then set its fields. See the
   [channel reference](#channel-reference).
5. Click <Icon.Play /> (**Start**).

The Console creates the channels. For a device with the identifier `dev1`, counter 0
gives `dev1_ctr_0`, with the index channel `dev1_ctr_time`.

  </Fragment>
  <Fragment slot="python">

Python does not create channels. Create them first.

```python
import synnax as sy
from synnax import ni

dev = client.devices.retrieve(key="<device key>")
time = client.channels.create(
    name="dev1_ctr_time", is_index=True, data_type=sy.DataType.TIMESTAMP
)
flow = client.channels.create(
    name="flow_meter_hz", index=time.key, data_type=sy.DataType.FLOAT64
)

task = ni.CounterReadTask(
    name="Flow meter",
    device=dev.key,
    sample_rate=100,
    stream_rate=10,
    channels=[
        ni.CIFrequencyChannel(port=0, min_val=1, max_val=1000, channel=flow.key)
    ],
)
client.tasks.configure(task)
task.start()
```

Python creates the task on the embedded Driver of the Core. For a device on another
Driver, use the Console or TypeScript. If you open the task in the Console and click
**Start**, the Console replaces your channels with its own.

  </Fragment>
  <Fragment slot="typescript">

TypeScript does not create channels. Create them first, as in the Python example.

```typescript
import { ni } from "@synnaxlabs/client";

const dev = await client.devices.retrieve({ key: "<device key>" });
const task = await client.tasks.create({
  name: "Flow meter",
  rack: dev.rack,
  type: "ni_counter_read",
  config: ni.counterReadConfigZ.parse({
    sampleRate: 100,
    streamRate: 10,
    channels: [
      {
        type: "ci_frequency",
        device: dev.key,
        port: 0,
        minVal: 1,
        maxVal: 1000,
        channel: flow.key,
      },
    ],
  }),
});
await task.start();
```

  </Fragment>
</Client.Tabs>

## Tare channels

Tare sets the current value of a channel to zero. The task must be running.

1. In the channel list, click **Tare** on a channel. To tare several channels, select
   them, right-click, and select **Tare**.
2. The values of those channels start from zero.

## Channel reference

Every channel has a `channel`, the Synnax channel that records the value, a `device`,
the key of the device (**Device**), and a `port`, the counter number (**Port**). In
Python, a channel with no `device` uses the `device` of the task.

The **Notes** column lists the values that code uses. The Console shows the same values
in plain words.

### Custom scaling

Channels with **Custom scaling** convert the raw value before the Driver writes it. In
the Console, the options are in the **Scale** section of the channel. In code, set
`custom_scale` to one of these scales:

| Console option | Python class      | Fields                                                                                                                         |
| -------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **None**       | `NoneScale`       | No scaling. This is the default.                                                                                               |
| **Linear**     | `LinearScale`     | **Slope** (`slope`, 1) and **Y-intercept** (`y_intercept`, 0).                                                                 |
| **Map**        | `MapScale`        | **Pre-scaled min** and **max** to **Scaled min** and **max** (`pre_scaled_min`, `pre_scaled_max`, `scaled_min`, `scaled_max`). |
| **Polynomial** | `PolynomialScale` | **Forward coefficients** (`forward_coeffs`) and **Reverse coefficients** (`reverse_coeffs`), from c0 up.                       |
| **Table**      | `TableScale`      | **Pre-scaled** and **Scaled** pairs (`pre_scaled_vals`, `scaled_vals`). A CSV file can fill them.                              |

Every scale except **None** also has **Prescaled units** (`pre_scaled_units`, `Volts`)
and **Scaled units** (`scaled_units`).

## Troubleshooting

### `Counter port ... has already been used on another channel on the same device`

<Problem.Body>
<Problem.Cause>

Two channels use the same counter of one device.

</Problem.Cause>
<Problem.Fix>

Change the port of one of them.

</Problem.Fix>
</Problem.Body>

### `No device provided for channel ...`

<Problem.Body>
<Problem.Cause>

A Python channel has no `device`, and the task has no `device` either.

</Problem.Cause>
<Problem.Fix>

Set one of them.

</Problem.Fix>
</Problem.Body>

### `Cannot create task with channels from multiple racks`

<Problem.Body>
<Problem.Cause>

The channels use devices on two Drivers.

</Problem.Cause>
<Problem.Fix>

Create one task for each Driver.

</Problem.Fix>
</Problem.Body>

For other problems, see
[Configure an NI device](/reference/hardware/ni/configure-device#troubleshooting) and
[Troubleshoot hardware](/reference/hardware/troubleshooting).
