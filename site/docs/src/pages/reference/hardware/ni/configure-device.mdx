The Driver connects to [National Instruments](https://www.ni.com/) hardware that works
with NI-DAQmx: CompactDAQ chassis and modules, USB and PCIe DAQ devices, and PXI. It
finds them through NI-DAQmx. Before a task can use a device, you configure it.

<Divider.Divider x />

## Prerequisites

<Platforms integration="ni" />

- Install
  [NI-DAQmx](https://www.ni.com/en/support/downloads/drivers/download.ni-daq-mx.html) on
  the computer that runs the Driver. On Windows, it includes NI System Configuration. If
  the Driver says that System Configuration is missing, install
  [NI System Configuration](https://www.ni.com/en/support/downloads/drivers/download.system-configuration.html).
- After you install, run the "Restart Synnax" command in Synnax Desktop, or restart the
  Driver.

<Divider.Divider x />

## How the Driver finds devices

The Driver looks for NI devices every few seconds. A device shows in the
[devices toolbar](/reference/hardware/devices#devices-toolbar) with:

- **Name** -> `NI` and the model, such as `NI 9205` or `NI USB-6343`.
- **Location** -> the name of the device in NI-DAQmx, such as `Dev1` or `cDAQ1Mod1`. The
  Driver uses it to address the ports of the device, such as `Dev1/ai0`.

The key of an NI device is its serial number. Modules show under their chassis. The
Driver skips CompactRIO controllers, but it finds the modules in them.

To stop the search, right-click the Driver in the devices toolbar and select **Toggle NI
device scanner**.

## Configure a device

<Client.Tabs exclude={["cpp"]}>
  <Fragment slot="console">

1. In the devices toolbar, right-click the device and select **Configure**. You can also
   click **Configure** in the "New ... connected" notification.
2. Enter a name, then click **Next**.
3. Enter an [identifier](/reference/hardware/devices#identifiers), then click **Save**.

Configure each module that a task uses.

<Video id="device-drivers/ni/configure-device/ni-configure-device" />

  </Fragment>
  <Fragment slot="python">

Find the NI devices that the Driver found:

```python
for dev in client.devices.retrieve(makes=["NI"]):
    print(dev.key, dev.name, dev.model, dev.location)
```

Configure devices in the Console. Python cannot set the identifier.

  </Fragment>
  <Fragment slot="typescript">

Find the NI devices that the Driver found:

```typescript
for (const dev of await client.devices.retrieve({ makes: ["NI"] }))
  console.log(dev.key, dev.name, dev.model, dev.location);
```

Configure devices in the Console.

  </Fragment>
</Client.Tabs>

Do not create NI devices in code. A device that you create has a different key than the
device that the Driver finds, and the Console cannot use it.

## Troubleshooting

### The device does not show in the devices toolbar

Install NI-DAQmx and restart the Driver. Check that NI MAX shows the device with a name.
The Driver skips a device that has no name. For more causes, see
[Troubleshoot hardware](/reference/hardware/troubleshooting#a-device-does-not-show-in-the-devices-toolbar).

### "Cannot create the task because the NI-DAQmx and System Configuration libraries are not installed"

Install the software in the [prerequisites](#prerequisites), then restart the Driver.

### "The device is temporarily unreachable. Will keep trying"

The Driver lost the connection to the device. Check the cable and the power. The task
continues when the device comes back.

For other problems, see [Troubleshoot hardware](/reference/hardware/troubleshooting).
