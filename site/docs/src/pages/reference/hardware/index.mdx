The Synnax Driver connects Synnax to your hardware. It reads data from devices into
channels, and it writes commands from channels to devices. The Driver also runs
[Arc automations](/reference/control/arc/introduction) close to the hardware.

You set up devices and [tasks](/reference/hardware/tasks) in the Console. The Driver
then runs each task in the background.

## Supported integrations

| Integration                                                     | Connects to                                         |
| --------------------------------------------------------------- | --------------------------------------------------- |
| [EtherCAT](/reference/hardware/ethercat/get-started)            | EtherCAT devices on a network interface             |
| [HTTP](/reference/hardware/http/connect-server)                 | Devices and services with an HTTP or HTTPS JSON API |
| [LabJack](/reference/hardware/labjack/configure-device)         | LabJack T-Series devices                            |
| [Modbus](/reference/hardware/modbus/connect-server)             | Modbus TCP/IP servers, such as PLCs and I/O modules |
| [National Instruments](/reference/hardware/ni/configure-device) | NI-DAQmx devices, such as CompactDAQ, cRIO, and PXI |
| [OPC UA](/reference/hardware/opc-ua/connect-server)             | OPC UA servers, such as PLCs and SCADA systems      |

Each integration has a table of the operating systems it supports. To send alerts to
[PagerDuty](/reference/alarms/pagerduty), see the alarms section.

## Embedded Driver

Synnax Desktop runs an embedded Driver for you. It starts and stops with the app, and
you do not install or configure it. The Driver can use only the hardware that connects
to the computer that runs Synnax Desktop.

<Edition.Enterprise>

Every [Synnax Core](/reference/enterprise) also runs an embedded Driver on the same
machine. It starts when the Core starts.

</Edition.Enterprise>

## Standalone Driver

<Edition.Enterprise>

With Synnax Enterprise, you can also
[install the Driver as a standalone program](/reference/enterprise/driver) on a
different machine from the Core. The standalone Driver connects to the Core over the
network. Use it to acquire data from hardware on more than one machine.

The standalone Driver runs on
[NI Linux Real-Time](https://www.ni.com/en/shop/linux/introduction-to-ni-linux-real-time.html)
controllers, such as [NI CompactRIO](https://www.ni.com/en/shop/compactrio.html) and
[NI PXI](https://www.ni.com/en/shop/pxi.html) systems.

On a real-time controller, the Driver runs data acquisition and control tasks and
[Arc automations](/reference/control/arc/introduction). Control loops then run close to
the hardware, with no latency from the network.

</Edition.Enterprise>

## Building a custom driver

If Synnax does not support your hardware, you can
[build a custom driver](/reference/hardware/custom) with the Python or TypeScript
client.
