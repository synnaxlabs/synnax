A LabJack read task reads the inputs of one LabJack device into channels. For example,
it can record a pressure transducer on `AIN0` and a switch on `DIO4` at 1 kHz.

Before you start, you need a
[configured device](/reference/hardware/labjack/configure-device).

<Divider.Divider x />

## Channels and timing

A read task has three types of channels:

- **Analog input** -> a voltage on an `AIN` port.
- **Digital input** -> the state of a `DIO` port, as 0 or 1.
- **Thermocouple** -> a temperature from a thermocouple on an `AIN` port. Thermocouples
  work on the T7 and the T8.

A task streams: the device samples the inputs on its own clock. A T7 task with
thermocouple channels polls instead: the Driver reads one sample of each channel at a
time, on its own clock. See [timing](/reference/hardware/tasks#timing).

A T8 task with thermocouple channels samples at 250 Hz or less. It needs T8 firmware
1.0038 or later and LJM 1.2304 or later.

A LabJack runs one stream at a time and cannot read `AIN` ports during a stream, so a
streaming task must be the only read task on its device. Add more channels to that task
instead of starting a second one.

A T7 with a Mux80 adds the analog inputs `AIN48` to `AIN127`. Each connector of the
Mux80 holds a group of them: `X3` holds `AIN48` to `AIN71`, `X4` holds `AIN72` to
`AIN95`, `X5` holds `AIN96` to `AIN119`, and `X2` holds `AIN120` to `AIN127`. In the
**Port** grid of a T7, select the tab of a connector to see its ports.

## Create a LabJack read task

<Client.Tabs>
  <Fragment slot="console">

1. In the devices toolbar, right-click the device and select **Create read task**.
2. Set **Sample rate** and **Stream rate**.
3. The task starts with one analog input channel. To add more, click **Add channel**, or
   select **Ports** above the channel list and click a free port. See
   [ports](/reference/hardware/tasks#ports).
4. Select a channel. In **Source**, select the type of channel, then click a port in the
   **Port** grid.
5. Click <Icon.Play /> (**Start**).

The Console creates the channels. For a device with the identifier `lj1`, the channel
for `AIN0` is `lj1_AIN0`, with the index channel `lj1_time`. To use a different name,
enter it in the channel list before you start the task.

  <Fragment slot="python">

Python does not create channels. Create them first.

```python
import synnax as sy
from synnax import labjack

dev = client.devices.retrieve(key="<serial number>")
time = client.channels.create(
    name="lj1_time", is_index=True, data_type=sy.DataType.TIMESTAMP
)
pressure = client.channels.create(
    name="lj1_AIN0", index=time.key, data_type=sy.DataType.FLOAT32
)
switch = client.channels.create(
    name="lj1_DIO4", index=time.key, data_type=sy.DataType.UINT8
)

task = labjack.ReadTask(
    name="Test stand inputs",
    device=dev.key,
    sample_rate=1000,
    stream_rate=25,
    channels=[
        labjack.AnalogReadChannel(port="AIN0", channel=pressure.key),
        labjack.DigitalReadChannel(port="DIO4", channel=switch.key),
    ],
)
client.tasks.configure(task)
task.start()
```

For a thermocouple on a T7 or a T8, use
`labjack.ThermocoupleReadChannel(port="AIN2", thermocouple_type="K", units="C", channel=...)`.

  </Fragment>

TypeScript does not create channels. Create them first.

```typescript
import { labjack } from "@synnaxlabs/client";

const dev = await client.devices.retrieve({ key: "<serial number>" });
const time = await client.channels.create({
  name: "lj1_time",
  isIndex: true,
  dataType: "timestamp",
});
const pressure = await client.channels.create({
  name: "lj1_AIN0",
  index: time.key,
  dataType: "float32",
});

const task = await client.tasks.create({
  name: "Test stand inputs",
  rack: dev.rack,
  type: "labjack_read",
  config: labjack.readConfigZ.parse({
    device: dev.key,
    sampleRate: 1000,
    streamRate: 25,
    channels: [{ type: "analog", port: "AIN0", channel: pressure.key }],
  }),
});
await task.start();
```

## Tare channels

Tare sets the current value of an analog channel to zero. The task must be running.

1. In the channel list, click **Tare** on an analog channel. To tare several channels,
   select them, right-click, and select **Tare**.
2. The values of those channels start from zero.

## Task options

| Console label | Python field           | Default | Notes                                                     |
| ------------- | ---------------------- | ------- | --------------------------------------------------------- |
| Device        | `device`               |         | The serial number of the device.                          |
| Sample rate   | `sample_rate`          | 10 Hz   | Up to 50,000 Hz in the Console.                           |
| Stream rate   | `stream_rate`          | 5 Hz    | See [read tasks](/reference/hardware/tasks#read-tasks).   |
| Data saving   | `data_saving_disabled` | On      | See [data saving](/reference/hardware/tasks#data-saving). |
| Auto start    | `auto_start`           | Off     | Starts the task each time the Driver starts.              |

## Channel reference

Each channel has a `channel`, the Synnax channel that records the value. Each table
shows the Console label of a setting, with its Python field under it.

<Channel.Types>

<Channel.Type
  name="Analog input"
  type="analog"
  python="AnalogReadChannel"
>

Reads a voltage.

| Setting                                    | Default | Notes                                                                                    |
| ------------------------------------------ | ------- | ---------------------------------------------------------------------------------------- |
| Port <small>`port`</small>                 | `AIN0`  | An `AIN` port.                                                                           |
| Max voltage <small>`range`</small>         | `10`    | The input uses the smallest range of the device that covers this voltage. Not on the T4. |
| Negative channel <small>`neg_chan`</small> | Ground  | Absent for ground, or the pair of the port for a differential reading. On the T7 only.   |
| Scale <small>`scale`</small>               | None    | See [scale](#scale).                                                                     |

</Channel.Type>

<Channel.Type
  name="Digital input"
  type="digital"
  python="DigitalReadChannel"
>

Reads the state of a digital line as 0 or 1, as `uint8`.

| Setting                    | Default | Notes         |
| -------------------------- | ------- | ------------- |
| Port <small>`port`</small> | `DIO4`  | A `DIO` port. |

</Channel.Type>

<Channel.Type
  name="Thermocouple"
  type="thermocouple"
  python="ThermocoupleReadChannel"
>

Reads a temperature from a thermocouple. The Driver reads the voltage of the
thermocouple and the temperature of its cold junction, then converts the two to a
temperature.

| Setting                                              | Default                | Notes                                                                                         |
| ---------------------------------------------------- | ---------------------- | --------------------------------------------------------------------------------------------- |
| Port <small>`port`</small>                           | `AIN0`                 | An `AIN` port.                                                                                |
| Thermocouple type <small>`thermocouple_type`</small> | `K`                    | `B`, `E`, `J`, `K`, `N`, `R`, `S`, `T`, `C`.                                                  |
| Temperature units <small>`units`</small>             | `K`                    | `C`, `F`, `K`.                                                                                |
| Negative channel <small>`neg_chan`</small>           | Ground                 | Absent for ground, or the pair of the port. On the T7 only.                                   |
| CJC source <small>`cjc_source`</small>               | `TEMPERATURE_DEVICE_K` | **Device** (**Terminal** on a T8), **Air** (not on a T8), or an `AIN` port with a CJC sensor. |
| CJC slope <small>`cjc_slope`</small>                 | `1`                    | The CJC sensor scale, in kelvin per volt.                                                     |
| CJC offset <small>`cjc_offset`</small>               | `0`                    | The CJC sensor offset, in kelvin.                                                             |
| Scale <small>`scale`</small>                         | None                   | Applied after the conversion to temperature. See [scale](#scale).                             |

</Channel.Type>

</Channel.Types>

### Scale

Analog input and thermocouple channels can scale the value before the Driver writes it.
In the Console, the options are in the **Scale** section of the channel. In code, set
`scale` to one of these classes from `synnax.labjack`:

| Console option | Python class      | Fields                                                                                                                         |
| -------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| None           | `NoneScale`       | No scaling. This is the default.                                                                                               |
| Linear         | `LinearScale`     | **Slope** (`slope`, 1) and **Offset** (`offset`, 0).                                                                           |
| Map            | `MapScale`        | **Pre-scaled min** and **max** to **Scaled min** and **max** (`pre_scaled_min`, `pre_scaled_max`, `scaled_min`, `scaled_max`). |
| Polynomial     | `PolynomialScale` | **Coefficients** (`coeffs`), from c0 up.                                                                                       |
| Table          | `TableScale`      | **Pre-scaled** and **Scaled** pairs (`pre_scaled_vals`, `scaled_vals`). A CSV file can fill them.                              |

## Troubleshooting

<Problem.List>

<Problem.Item message={"Falling behind hardware"}>
<Problem.Cause>

The Driver cannot send the samples as fast as the device makes them.

</Problem.Cause>
<Problem.Fix>

Lower the **Stream rate**, or lower the **Sample rate**.

</Problem.Fix>
</Problem.Item>

<Problem.Item message={"Skipped samples"}>
<Problem.Cause>

The buffer of the device filled, so the device skipped samples. The Driver writes no
value for a skipped sample.

</Problem.Cause>
<Problem.Fix>

Lower the **Sample rate**, or check the USB cable or the network.

</Problem.Fix>
</Problem.Item>

<Problem.Item message={"Thermocouple out of range"}>
<Problem.Cause>

The voltage of the thermocouple is outside the range of its **Thermocouple type**. The
thermocouple is open, a wire is loose, or the type is wrong. The Driver writes NaN until
the voltage is in range.

</Problem.Cause>
<Problem.Fix>

Check the wires of the thermocouple and its **Thermocouple type**.

</Problem.Fix>
</Problem.Item>

<Problem.Item message={"A T8 task with thermocouples samples at 250 Hz or less"}>
<Problem.Cause>

Above 250 Hz, the T8 cannot read the temperature at its terminals, which the Driver
needs to convert thermocouples.

</Problem.Cause>
<Problem.Fix>

Set the **Sample rate** to 250 Hz or less.

</Problem.Fix>
</Problem.Item>

<Problem.Item message={"Thermocouples on a T8 need firmware ... or later"}>
<Problem.Cause>

The firmware of the T8 cannot stream the temperature at its terminals.

</Problem.Cause>
<Problem.Fix>

Update the firmware of the T8 with [Kipling](https://support.labjack.com/docs/kipling).

</Problem.Fix>
</Problem.Item>

<Problem.Item message={"Thermocouples on a T8 need LJM ... or later"}>
<Problem.Cause>

The LJM library on the computer that runs the Driver cannot stream the temperature at
the terminals of a T8.

</Problem.Cause>
<Problem.Fix>

Install the latest
[LJM](https://support.labjack.com/docs/ljm-software-installer-downloads-t4-t7-t8-digit),
then restart the Driver.

</Problem.Fix>
</Problem.Item>

<Problem.Item message={"Using default calibration"}>
<Problem.Cause>

The calibration constants of the device are not valid. LJM uses default constants, so
readings may be inaccurate. The task continues to record data.

</Problem.Cause>
<Problem.Fix>

Contact [LabJack support](https://labjack.com/pages/support).

</Problem.Fix>
</Problem.Item>

<Problem.Item message={"... is a thermocouple channel, but the T4 does not support thermocouples."}>
<Problem.Cause>

The T4 has no thermocouple inputs.

</Problem.Cause>
<Problem.Fix>

Use a T7 or a T8 for thermocouple channels.

</Problem.Fix>
</Problem.Item>

<Problem.Item message={"... is a thermocouple channel, so it cannot be the CJC source of ..."}>
<Problem.Cause>

The **CJC source** of a thermocouple is the port of another thermocouple channel. A
thermocouple port has no CJC sensor.

</Problem.Cause>
<Problem.Fix>

Set **CJC source** to **Device**, or to the `AIN` port of a CJC sensor.

</Problem.Fix>
</Problem.Item>

<Problem.Item message={"... has a max voltage of ..., but the largest range of the device is ..."}>
<Problem.Cause>

The **Max voltage** of the channel is larger than the largest input range of the device:
±10 V on a T7, and ±11 V on a T8.

</Problem.Cause>
<Problem.Fix>

Lower the **Max voltage** of the channel.

</Problem.Fix>
</Problem.Item>

<Problem.Item symptom={"A T7 task fails to start after a change to Max voltage."}>
<Problem.Cause>

On a T7, a small range takes longer to settle. A task with more than one channel and a
**Max voltage** of 1 V or less can then not stream at its **Sample rate**.

</Problem.Cause>
<Problem.Fix>

Lower the **Sample rate**, or set **Max voltage** back to 10. See LabJack's
[stream rates](https://support.labjack.com/docs/a-1-1-stream-data-rates-t-series-datasheet).

</Problem.Fix>
</Problem.Item>

<Problem.Item message={"Another channel uses FIO4"}>
<Problem.Cause>

Two enabled channels use the same port.

</Problem.Cause>
<Problem.Fix>

Select a different port for one of the channels, or disable one of them.

</Problem.Fix>
</Problem.Item>

<Problem.Item message={"A LabJack runs one stream at a time, and another task is streaming from this device."}>
<Problem.Cause>

Another read task streams from the same device. A LabJack runs one stream at a time.

</Problem.Cause>
<Problem.Fix>

Add the channels of this task to the running task, then delete this task.

</Problem.Fix>
</Problem.Item>

</Problem.List>

For other problems, see
[Configure a LabJack device](/reference/hardware/labjack/configure-device#troubleshooting)
and [Troubleshoot hardware](/reference/hardware/troubleshooting).
