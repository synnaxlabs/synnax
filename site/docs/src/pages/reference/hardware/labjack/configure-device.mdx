## Prerequisites

Before you use your LabJack hardware with Synnax, make sure that you have:

1. [Synnax Desktop](/reference/) installed on the computer that your LabJack hardware
   connects to.
2. The
   [LJM library](https://support.labjack.com/docs/ljm-software-installer-downloads-t4-t7-t8-digit)
   installed on the same computer.

<Edition.Enterprise>

With Synnax Enterprise, you need a [Synnax Core](/reference/enterprise) and a Synnax
Driver that runs on the machine that your LabJack hardware connects to. A Core runs an
embedded Driver on its own machine. For a different machine,
[install a standalone Driver](/reference/enterprise/driver/install). Install the LJM
library on the machine that runs the Driver. Install the
[Synnax Console](/reference/enterprise/console) on your computer.

</Edition.Enterprise>

## Configuration parameters reference

| Parameter         | Type   | Required | Description                                                             |
| ----------------- | ------ | -------- | ----------------------------------------------------------------------- |
| `name`            | string | Yes      | Human-readable device name for identification in Console                |
| `rack`            | string | Yes      | Synnax Driver (rack) key where the device is connected                  |
| `model`           | string | Yes      | LabJack model (`LJM_dtT4`, `LJM_dtT7`, or `LJM_dtT8`)                   |
| `location`        | string | Yes      | Physical connection identifier (see below)                              |
| `identifier`      | string | Yes      | Device identifier: serial number, IP address, device name, etc.         |
| `connection_type` | string | No       | Connection method: `ANY` (default), `USB`, `TCP`, `ETHERNET`, or `WIFI` |

<Note.Note variant="info" className="compact">
  `connection_type` is only supported through the Python and TypeScript client
  libraries.
</Note.Note>

```python
import synnax as sy
from synnax import labjack

# Connect to Synnax
client = sy.Synnax()

# Get the embedded rack (local driver rack)
rack = client.racks.retrieve_embedded_rack()

# Configure device connection
device = labjack.Device(
    model=labjack.T7,                 # Model: T4, T7, T8
    identifier="ANY",                 # Serial number, IP, name, or "ANY"
    name="My LabJack T7",             # Device name
    location="ANY",                   # Connection identifier
    rack=rack.key,                    # Rack key
    connection_type="ANY",            # "ANY", "USB", "TCP", "ETHERNET", "WIFI"
)

# Create the device in Synnax
device = client.devices.create(device)

# Or retrieve by model
device = client.devices.retrieve(model="LJM_dtT7")

# Or retrieve by name
device = client.devices.retrieve(name="My LabJack T7")

print(f"Device configured: {device.name} (key={device.key})")
```

```typescript
import { Synnax } from "@synnaxlabs/client";

// Connect to Synnax
const client = new Synnax();

// Get the embedded rack (local driver rack)
const [rack] = await client.racks.retrieve({ embedded: true });

// Configure device connection
const device = await client.devices.create({
  key: crypto.randomUUID(),
  rack: rack.key,
  name: "My LabJack T7",
  make: "LabJack",
  model: "LJM_dtT7", // Model: LJM_dtT4, LJM_dtT7, LJM_dtT8
  location: "ANY", // Connection identifier
  properties: {
    connection: {
      identifier: "ANY", // Serial number, IP, name, or "ANY"
      connectionType: "ANY", // "ANY", "USB", "TCP", "ETHERNET", "WIFI"
    },
    read: {
      index: 0,
      channels: {},
    },
    write: {
      channels: {},
    },
  },
});

// Or retrieve by model
const [byModel] = await client.devices.retrieve({ models: ["LJM_dtT7"] });

// Or retrieve by name
const [byName] = await client.devices.retrieve({ names: ["My LabJack T7"] });

console.log(`Device configured: ${device.name} (key=${device.key})`);
```
