## `select`

Sends each trigger value to its `true` output or its `false` output.

- Trigger -> a `bool` value from `->`. Another type, such as `u8`, is an error. A `=>`
  into `select` gives the error `'=>' cannot feed select(), use '->'`.
- Outputs -> `true` and `false`, both `u8`. Each `true` trigger value emits 1 on `true`.
  Each `false` trigger value emits 1 on `false`.
- Runs -> on each new trigger value.

`select` has no parameters. Connect its outputs with an
[output routing table](/reference/control/arc/reference/flow). Each entry is optional.

```arc channels="vlv_open, open_cmd, close_cmd"
vlv_open -> select() -> {
    true: 1 -> open_cmd,
    false: 1 -> close_cmd
}
```

For more than two outputs, write a function with named outputs. See
[functions](/reference/control/arc/reference/functions). `select` works the same on the
Core and on a Driver.
