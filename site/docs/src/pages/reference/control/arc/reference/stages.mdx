A stage runs all of its items at the same time, while it is active. Newlines or commas
separate the items. To learn what happens when a stage starts and stops, see
[entering a stage](/reference/control/arc/execution-model#entering-a-stage).

```text
stage = "stage" name? ("(" params ")")? "{" item* "}"
```

```arc channels="start_cmd, abort_cmd, press_vlv_cmd, vent_vlv_cmd, tank_pt, tank_alarm" bodies="press, pressurize, hold, vent, abort, monitor"
import time

sequence press {
    stage pressurize {
        abort_cmd => abort
        tank_pt > 500 => abort
        true -> press_vlv_cmd
        tank_pt > 300 => next
    }
    stage hold {
        abort_cmd => abort
        false -> press_vlv_cmd
        time.wait(duration=30s) => next
    }
    stage vent {
        true -> vent_vlv_cmd
    }
    stage abort {
        false -> press_vlv_cmd
        true -> vent_vlv_cmd
    }
}

stage monitor(pressure chan f32, limit f32, alarm chan bool) {
    pressure > limit -> alarm
}

start_cmd => press
start_cmd => monitor(tank_pt, 450, tank_alarm)
```

## Stage body

| Item                 | Example                                    |
| -------------------- | ------------------------------------------ |
| Flow                 | `tank_pt -> scale(k=6.895) -> tank_pt_kpa` |
| Transition           | `tank_pt > 500 => abort`                   |
| Function call        | `monitor()`                                |
| Variable declaration | `peak $= 0.0`                              |
| Assignment           | `target = 400.0`                           |
| Sequence             | `sequence { ... }`                         |

A sequence in a stage runs its steps in order, while the other items of the stage keep
running. A stage cannot contain a stage. When more than one transition is true in the
same cycle, the first one in the code wins. See
[conditions and transitions](/reference/control/arc/execution-model#conditions-and-transitions).

## Transitions

| Transition | Effect                                                                        |
| ---------- | ----------------------------------------------------------------------------- |
| `=> next`  | Ends this stage. Its sequence moves to the next step, or ends after the last. |
| `=> name`  | Moves to the named step of the same sequence, also an earlier step.           |
| `=> other` | Starts a copy of the top-level sequence or stage `other` inside this stage.   |

A stage of a different sequence is not a valid target: `undefined symbol: name`.

This stage keeps running while a copy of a top-level target runs, and the copy stops
when this stage stops. Each flow that names the target starts its own copy.

## Top-level stages

A named top-level stage runs only after a `=> name` starts it. An anonymous top-level
stage runs for as long as the automation runs. A named top-level stage can take
[parameters](/reference/control/arc/reference/flow#stage-and-sequence-parameters).

```arc channels="tank_pt, alarm_cmd" bodies="alarm"
func alarm() {
    alarm_cmd = true
}

stage {
    tank_pt > 500 => alarm()
}
```

In a top-level stage, `=> next` ends the stage.
