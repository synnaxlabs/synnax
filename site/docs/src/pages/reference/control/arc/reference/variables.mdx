A variable gives a name to a value or to a channel. This page tells you how to declare
variables, where they are visible, and how to change them.

<Divider.Divider x />

## Declaration

| Form              | Example            | Declares                         |
| ----------------- | ------------------ | -------------------------------- |
| `name := value`   | `limit := 500.0`   | A variable. Arc infers the type. |
| `name T := value` | `count i32 := 0`   | A variable of type `T`.          |
| `name $= value`   | `prev $= 0.0`      | A stateful variable.             |
| `name T $= value` | `total f32 $= 0.0` | A stateful variable of type `T`. |

For types and inference, see [types](/reference/control/arc/reference/types). What the
variable holds depends on its value:

| Value                             | Example                  | The variable                                                          |
| --------------------------------- | ------------------------ | --------------------------------------------------------------------- |
| A literal or an expression        | `limit := 500.0`         | Holds the value.                                                      |
| A channel name                    | `vlv := press_vlv_cmd`   | Is a second name for the channel. It reads and writes the channel.    |
| An expression that reads channels | `kpa := tank_pt * 6.895` | Is read-only. It gets a new value each time one of the channels does. |

### Where you can declare

| Place     | `:=`                          | `$=` | `=` | `+=` and `x[i] =` |
| --------- | ----------------------------- | ---- | --- | ----------------- |
| Top level | Yes. The value is a constant. | No   | No  | No                |
| Function  | Yes                           | Yes  | Yes | Yes               |
| Sequence  | Yes                           | Yes  | Yes | No                |
| Stage     | Yes                           | Yes  | Yes | No                |

At the top level, `$=` fails with
`stateful variables cannot be declared at the top level`. An assignment fails with
`cannot reassign a top-level variable; assignment is only valid inside a sequence, stage, or function`.
In a sequence or stage, compound and indexed assignment fail with
`compound and indexed assignment to a variable are not yet supported`.

## Stateful

A `$=` variable keeps its value between calls of its function. A `:=` variable in a
function gets its first value again on each call.

```arc channels="tank_pt, tank_pt_delta" bodies="delta"
func delta() {p f64} f64 {
    prev $= 0.0
    d := p - prev
    prev = p
    return d
}

tank_pt -> delta() -> tank_pt_delta
```

In a function, the first value of a `$=` variable can be any expression, a channel read
included. It runs on the first call only.

When a stage starts, the `:=` variables of the stage and its sequence, and the `$=`
variables of the functions it calls, go back to their first values. See
[entering a stage](/reference/control/arc/execution-model#entering-a-stage).

In a stage or sequence, the first value of a `$=` variable is a literal or an expression
that reads no channel. A computed one runs once, on the first entry of its scope. A
channel fails with
`channels and channel-read expressions cannot be assigned to stateful variables`.

## Scope

A variable is visible from its declaration to the end of the block that holds it. Inner
blocks see the variables of outer blocks. A use before the declaration fails with
`undefined symbol: x`.

A name cannot be declared again in an inner block:

```arc bodies="clamp"
func clamp() {x f64} f64 {
    y := x
    if y > 100.0 {
        y = 100.0
    }
    return y
}
```

Writing `y := 100.0` in the `if` block fails with
`name y conflicts with existing variable at line 2, col 4`. A variable can use the name
of a standard library function, such as `min`.

## Assignment

`=` gives a variable a new value. For `+=`, `-=`, `*=`, `/=`, and `%=`, see
[compound assignment](/reference/control/arc/reference/statements#compound-assignment).

- The value must have the type of the variable.
- `+=` also appends to a `str`. Strings support no other compound operator.
- `data[i] = v` sets one element of a series.
- You cannot assign to a `for` loop variable: `cannot assign to loop variable 'i'`.
- In a stage or sequence, a flow can also write a variable: `tank_pt -> peak`. Compound
  and indexed assignment work only in a function.
- `=` on a channel name variable points it at a different channel of the same type. `=`
  on a read-only variable gives it a new expression.

## Channels in code

In a stage, a sequence, or at the top level, read and write channels with flows. See
[flow](/reference/control/arc/reference/flow).

In a function body, a channel name gives the latest value of the channel, or `0` before
the first value. Write to a channel with `=`. A `->` in a function body is a syntax
error.

```arc channels="tank_pt, setpoint, press_vlv_cmd" bodies="regulate"
func regulate() {p f64} {
    if p > setpoint {
        press_vlv_cmd = 0
    }
}

tank_pt -> regulate()
```

A read-only variable cannot take a write: `1.0 -> kpa` fails with
`cannot write to channel-read variable kpa; it is read-only`.
