The Arc compiler checks the code while you type, and the editor marks each problem. Each
diagnostic has a line and a column, a severity, a message, and sometimes a code and a
note. An error stops the automation from compiling. A warning does not. In a status, a
diagnostic looks like this:

```text
5:14 error [ARC3001]: missing required argument for parameter 'y' of func 'add'
  note: signature: add(x f64, y f64) f64
```

In the messages below, `<name>` stands for a value that changes.

## Diagnostic codes

<Field.List>

<Field.Item name="ARC3001" id="arc3001">

Error. `missing required argument for parameter '<p>' of func '<f>'`, or
`too many arguments for func '<f>': expected at most <n>`. The call has too few or too
many arguments. Match the signature in the note.

</Field.Item>

<Field.Item name="ARC3002" id="arc3002">

Error. `type mismatch in argument '<p>' of '<f>': expected <T>, got <U>`. An argument
has the wrong type. Convert the value. For a duration in a variable, declare the
variable as `i64 ns`.

</Field.Item>

<Field.Item name="ARC4003" id="arc4003">

Warning. `'<old>' is deprecated, use '<new>' instead`. The code uses an old name, such
as `interval`. Use the qualified name, such as `time.interval`.

</Field.Item>

<Field.Item name="ARC5001" id="arc5001">

Error. `imported module "<m>" is unused`. The code imports a module and does not use it.
Remove the import.

</Field.Item>

</Field.List>

Codes ARC2001, ARC2003, ARC4001, and ARC4002 are reserved. The compiler does not emit
them.

## Common messages without a code

These tables list the most common diagnostics without a code, not all of them.

### Syntax, imports, and names

| Message                                                                 | Cause                                                                                                                                   | Fix                                                                                          |
| ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `mismatched input '<x>' expecting <tokens>`                             | The syntax is not correct at that position.                                                                                             | Correct the code at the line and column.                                                     |
| `token recognition error at: '<c>'`                                     | The character is not part of Arc, such as `&`.                                                                                          | Use the Arc operator, such as `and`.                                                         |
| `unknown unit: <text>`                                                  | A number has a suffix that is not a unit, such as `0xFF` or `1e3`. In a function body, the error shows only when the automation starts. | Write the number in decimal digits.                                                          |
| `unknown module "<m>"`                                                  | No module has that name.                                                                                                                | Use a module from the [standard library](/reference/control/arc/reference/standard-library). |
| `duplicate import: "<m>" is already imported`                           | The code imports the module two times.                                                                                                  | Remove one import.                                                                           |
| `import statements must appear before any other top-level declarations` | An import comes after other code.                                                                                                       | Move the imports to the top of the file.                                                     |
| `undefined symbol: <name>`                                              | The name is not declared, the channel does not exist, or the module is not imported. A note gives the `import` to add.                  | Declare the name, correct the channel name, or add the import.                               |
| `name <x> conflicts with existing <kind> at line <l>, col <c>`          | Two declarations in the same scope have the same name.                                                                                  | Rename one of them.                                                                          |

### Types and expressions

| Message                                                                                                     | Cause                                                                         | Fix                                         |
| ----------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | ------------------------------------------- |
| `type mismatch: cannot assign <T> to '<name>' (type <U>)`                                                   | The value and the variable have different types.                              | Convert the value, such as `f64(x)`.        |
| `cannot use <T> in <op> operation`                                                                          | The operator does not take that type, such as `x and true` with a number `x`. | Use a comparison, such as `x > 0 and true`. |
| `boolean conversions are not supported; define the comparison explicitly, e.g. x != 0 or abs(x - 1) < 0.01` | The code casts a value to `bool`.                                             | Write a comparison, such as `x != 0`.       |

### Variables and functions

| Message                                                                                                | Cause                                                                    | Fix                                                  |
| ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------ | ---------------------------------------------------- |
| `cannot reassign a top-level variable; assignment is only valid inside a sequence, stage, or function` | A top-level variable is a constant.                                      | Assign it inside a sequence, a stage, or a function. |
| `stateful variables cannot be declared at the top level`                                               | A `$=` declaration is at the top level.                                  | Declare it in a sequence, a stage, or a function.    |
| `cannot assign to loop variable '<i>'`                                                                 | The loop body changes the loop variable.                                 | Use a different variable.                            |
| `function '<f>' must return a value of type <T> on all paths`                                          | One path through the function has no `return`.                           | Add a `return` to each path.                         |
| `cannot return a value from a function with no return type`                                            | `return x` in a function without an output type, or with a named output. | Add an output type, or assign the named output.      |
| `function '<f>' cannot be called inside a func block. Use it as a flow statement instead: <f>{}`       | A function body calls a flow function, such as `math.avg`.               | Use the function in a flow.                          |
| `unknown parameter '<p>' for func '<f>'`                                                               | The function has no parameter with that name.                            | Use a name from the signature in the note.           |
| `duplicate argument for parameter '<p>' of func '<f>'`                                                 | The call gives the same parameter two times.                             | Remove one argument.                                 |

### Flows, sequences, and stages

| Message                                                                              | Cause                                                                                           | Fix                                                                     |
| ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `input value for '<p>' must be a literal`                                            | A parameter in `{}` gets a channel or an expression.                                            | Use a literal or a variable.                                            |
| `upstream value type <T> does not match func '<f>' trigger parameter '<p>' type <U>` | The flow sends the wrong type into the function, such as a `bool` into `control.set_authority`. | Send a value of the type that the function takes.                       |
| `<source> value type <T> does not match channel <ch> value type <U>`                 | A flow writes one channel type to a channel of another type.                                    | Convert the value in a function, or use a channel of the same type.     |
| `func <f> output type <T> does not match channel <ch> value type <U>`                | The function output and the channel have different types.                                       | Use a channel of the output type.                                       |
| `<name> is not a function`                                                           | `{}` follows a name that is not a function.                                                     | Call a function, or remove the `{}`.                                    |
| `'=>' cannot feed select{}, use '->'`                                                | A `=>` sends values into `select`.                                                              | Use `->`.                                                               |
| `input routing tables not yet implemented in text compiler`                          | The code uses an input routing table.                                                           | Set the extra parameters in `{}`, or call the function from a function. |
| `'next' used outside of a sequence`                                                  | A `=> next` is in a top-level stage or flow.                                                    | Move it into a sequence.                                                |
| `'next' in last stage '<s>' has no next stage`                                       | The last stage of a sequence uses `=> next`.                                                    | Add a step after it, or go to a named stage.                            |
| `sequence '<s>' has no steps`                                                        | The sequence is empty.                                                                          | Add a step.                                                             |

### Authority and standard library arguments

| Message                                                                                          | Cause                                                | Fix                                         |
| ------------------------------------------------------------------------------------------------ | ---------------------------------------------------- | ------------------------------------------- |
| `authority declaration must appear before function, flow, and sequence declarations`             | Other code comes before `authority`.                 | Move `authority` to just after the imports. |
| `multiple default authority values`                                                              | The declaration has more than one default.           | Keep one default.                           |
| `duplicate authority for '<ch>'`                                                                 | A channel has more than one value.                   | Keep one value for the channel.             |
| `channel '<ch>' not found`                                                                       | The declaration names a channel that does not exist. | Correct the channel name.                   |
| `authority value must be an integer in range 0-255, got '<v>'`                                   | The value is outside 0 to 255.                       | Use a value from 0 to 255.                  |
| `<param> must be positive, got <span>`                                                           | A timer has a `period` or `duration` of 0 or less.   | Use a positive duration.                    |
| `"<v>" is not a valid status variant: [success, info, warning, error, loading, disabled]`        | `status.set` has an unknown `variant`.               | Use a variant from the list.                |
| For example, `color must be a hex value (e.g. "#3bc454") or rgb(r,g,b): "<v>": validation error` | `ranges.create` has a `color` that is not a color.   | Use a hex, `rgb()`, or `rgba()` color.      |
| `stable.for input must be a numeric or bool type, got <T>`                                       | `stable.for` gets a `str` value.                     | Send a numeric or `bool` value.             |

### Errors when the automation starts

These errors come from the last compile step. The editor does not mark them, and they
have no line number. They show in the status when the automation starts, after a prefix
that names the place, such as:

```text
failed to compile function 'f' body: failed to compile return expression: float modulo not yet implemented
```

| Message                                                                | Cause                                                                            | Fix                                                         |
| ---------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| `float modulo not yet implemented`                                     | The code uses `%` on floats.                                                     | Use `%` on integers only.                                   |
| `cannot read '<name>': its initializer is not a compile-time constant` | Code reads a top-level variable whose value is not a constant, such as a series. | Declare the variable in the function or stage that uses it. |

### Warnings without a code

| Message                                                                     | Cause                                           | Fix                                   |
| --------------------------------------------------------------------------- | ----------------------------------------------- | ------------------------------------- |
| `numeric conditions are deprecated; use an explicit comparison like x != 0` | An `if` or a `=>` uses a number as a condition. | Write a comparison, such as `x != 0`. |

## Errors while it runs

Errors while an automation runs have no code. Examples are an integer division by zero
and a failed `status.set` or `ranges` call. On the Core, Synnax shows a warning and the
automation keeps running. On a Driver, an error stops the automation, and a warning does
not. For the full rules, see
[errors while it runs](/reference/control/arc/execution-model#errors-while-it-runs).
