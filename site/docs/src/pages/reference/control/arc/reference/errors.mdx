The editor marks each problem while you type. An error stops the automation from
compiling. A warning does not. In a status, a diagnostic looks like this:

```text
5:14 error [E3001]: missing required argument: parameter 'y' of func 'add'
  note: signature: add(x f64, y f64) f64
```
