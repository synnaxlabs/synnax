Every value in Arc has a type that the compiler knows before the automation runs. Arc
never converts a value to a different type for you, except for literals.

<Divider.Divider x />

## Primitive types

| Type   | Values                                     |
| ------ | ------------------------------------------ |
| `i8`   | Signed 8-bit integer, -128 to 127          |
| `i16`  | Signed 16-bit integer, -32,768 to 32,767   |
| `i32`  | Signed 32-bit integer                      |
| `i64`  | Signed 64-bit integer                      |
| `u8`   | Unsigned 8-bit integer, 0 to 255           |
| `u16`  | Unsigned 16-bit integer, 0 to 65,535       |
| `u32`  | Unsigned 32-bit integer                    |
| `u64`  | Unsigned 64-bit integer                    |
| `f32`  | 32-bit float, about 7 digits of precision  |
| `f64`  | 64-bit float, about 15 digits of precision |
| `bool` | `true` or `false`                          |
| `str`  | Text                                       |

To give a variable a type, write the type after the name:

```arc bodies="types"
func types() {
    count i32 := 0
    ratio f32 := 0.5
    name str := "tank"
}
```

## Numeric literals

A numeric literal takes the type that its place in the code needs. With no such type, an
integer literal is an `i64` and a float literal is an `f64`.

| Literal | Where it can go                    |
| ------- | ---------------------------------- |
| `42`    | Any integer or float type          |
| `2.0`   | Any float type, or an integer type |
| `2.5`   | Float types only                   |

A value too large for its type is a compile error, for example
`value 300 out of range for u8 (must be in [0, 255])`. A fraction where Arc needs an
integer fails with a message that ends in `float is not compatible with i32`.

```arc bodies="scale"
func scale() {x i32} i32 {
    return x * 2   // 2 is an i32 here
}
```

A float can also hold NaN or infinity. `math.nan` and `math.inf` act like a float
literal: they fit `f32` or `f64`, and they default to `f64`. `x i32 := math.inf` fails
to compile. See [`math`](/reference/control/arc/standard-library/math#float-constants).

## Casts

Write the type name and the value in parentheses: `f64(x)`.

| From    | To      | Result                                                              |
| ------- | ------- | ------------------------------------------------------------------- |
| Integer | Float   | The same number                                                     |
| Float   | Integer | Truncated toward zero. Out of range or NaN fails at runtime.        |
| `bool`  | `u8`    | `1` or `0`                                                          |
| Number  | `str`   | Shortest form: `str(1.0)` is `"1"`, and `"NaN"`, `"+Inf"`, `"-Inf"` |
| `bool`  | `str`   | `"true"` or `"false"`                                               |

```arc channels="tank_pt, tank_high" bodies="high"
func high() {p f64} u8 {
    return u8(p > 300.0)
}

tank_pt -> high() -> tank_high
```

| Cast                                         | Compiler message                                                                                            |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| To `bool`, `bool(x)`                         | `boolean conversions are not supported; define the comparison explicitly, e.g. x != 0 or abs(x - 1) < 0.01` |
| From `str`, `i64(s)`                         | `cannot cast str to i64`                                                                                    |
| `bool` to a number other than `u8`, `i32(b)` | Warning: `bool to i32 is experimental; a future release may only allow bool to u8`                          |

## Channels

A channel name in code refers to a Synnax channel. You do not declare channels. The type
of a channel is `chan T`, where `T` is its data type, such as `chan f64`.

| Where                             | What the channel name gives                                 |
| --------------------------------- | ----------------------------------------------------------- |
| Start of a flow                   | Each new value. The flow runs when a value arrives.         |
| End of a flow                     | A write of the value that reaches it.                       |
| Expression at the start of a flow | Each new value of every channel in the expression.          |
| Function body                     | The latest value, or the zero value before the first value. |

The zero value is `0` for numbers and `false` for `bool`. For when each part runs, see
the [execution model](/reference/control/arc/execution-model).

In a function body, write to a channel with `=`. A function can also take a channel as
an input of type `chan T`:

```arc channels="tank_pt, press_vlv_cmd" bodies="regulate"
func regulate(valve chan u8, limit f64) {p f64} {
    if p > limit {
        valve = 0
    }
}

tank_pt -> regulate(valve=press_vlv_cmd, limit=500.0)
```

The data types must match. Passing an `f64` channel to a `chan i32` parameter named
`sensor` of a function `count` fails with `ARC3002`:
`type mismatch in argument 'sensor' of 'count' (element types): expected i32, got f64`.

## Series

A series is a list of values of one primitive type, such as `series f64`.

| Operation      | Example              | Result                           |
| -------------- | -------------------- | -------------------------------- |
| Literal        | `[1.0, 2.0, 3.0]`    | `series f64`                     |
| Empty          | `e series f64 := []` | An empty `series f64`            |
| Untyped empty  | `e := []`            | Typed by its first use           |
| Length         | `len(data)`          | `i64`                            |
| Index          | `data[0]`            | The first element                |
| Slice          | `data[1:3]`          | Elements 1 and 2                 |
| Set an element | `data[0] = 5.0`      | Changes element 0                |
| Arithmetic     | `data * 2.0`         | A new series, element by element |
| Comparison     | `data > 2.0`         | A `series bool`                  |
| Logical        | `not mask`           | A `series bool`                  |
| Loop           | `for x := data { }`  | Each element in turn             |

```arc bodies="peak"
func peak() f64 {
    data := [1.0, 4.0, 2.0]
    gain := [2.0, 2.0, 2.0]
    scaled := data * gain
    top := 0.0
    for x := scaled {
        if x > top {
            top = x
        }
    }
    return top
}
```

- An operation on two series needs series of the same length. Different lengths cause a
  runtime error.
- An untyped `[]` takes its element type from its first typed write or use. `e[0] = n`
  with `n i32` gives `series i32`, and `e = [true]` or `not e` gives `series bool`.
  Number literals and arithmetic keep it numeric: `e += 1` then `e += 1.5` is valid. If
  nothing else sets the type, it is `series f64`.
- After that, a value of another type fails. `e[0] = 1` then `e[0] = true` fails with
  `bool is not compatible with numeric`.
- `w series f64 := e` with an untyped empty `e` fails. Give the literal its type:
  `e series f64 := []`.
- Put a series literal in a variable before you use it in an operation.
  `data + [1.0, 2.0]` fails with `series literal requires series type hint`.
- A slice is a series. `sub := data[1:3]` gives `series f64`, and `x f64 := data[1:3]`
  fails with `cannot assign series f64 to 'x' (type f64)`.
- A slice is a copy. A write to `sub` does not change `data`.
- A negative slice bound counts from the end, so `data[0:-1]` drops the last element. A
  bound outside the series stops at the nearer end.
- A negative index counts from the end. An index outside the series is an error. See
  [errors while it runs](/reference/control/arc/execution-model#errors-while-it-runs).
- A top-level series is not a constant. Its declaration fails with
  `variable 'data' of type series f64 cannot have a computed initializer`.

## Strings

| Operation | Example          | Result                     |
| --------- | ---------------- | -------------------------- |
| Join      | `"tank " + name` | `str`                      |
| Append    | `msg += "!"`     | `str`                      |
| Compare   | `name == "ok"`   | `bool`. Also `!=`.         |
| Length    | `len(name)`      | `i64`, the length in bytes |

Strings have no index, no slice, and no `<` or `>`. To put values in text, use
[format strings](/reference/control/arc/reference/syntax#format-strings).

## Units

A type can carry one unit after the type name: `f64 psi`, `i64 ns`. A literal gets a
unit from its suffix: `14.7psi`, `50ms`. Arc checks units at compile time.

A value is the number in the unit of its type, so `p := 14.7psi` holds `14.7`.

A number with no unit takes the unit of the value that it is added to, compared with, or
written to. With `x := 400.0`, `x > 300psi` compares `400.0` with `300.0`.

| Dimension   | Units                                                                          |
| ----------- | ------------------------------------------------------------------------------ |
| Time        | `ns` `us` `ms` `s` `min` `h` `d`                                               |
| Frequency   | `Hz` `hz` `kHz` `khz` `MHz` `mhz` `GHz`                                        |
| Length      | `fm` `pm` `nm` `um` `mm` `cm` `dm` `m` `meter` `km` `in` `ft` `yd` `mi` `nmi`  |
| Mass        | `fg` `pg` `ng` `ug` `mg` `g` `kg` `lb` `oz` `ton`                              |
| Pressure    | `pPa` `nPa` `uPa` `mPa` `Pa` `kPa` `MPa` `GPa` `bar` `mbar` `psi` `atm` `torr` |
| Voltage     | `fV` `pV` `nV` `uV` `mV` `V` `kV` `MV`                                         |
| Current     | `fA` `pA` `nA` `uA` `mA` `A` `kA` `MA`                                         |
| Temperature | `fK` `pK` `nK` `uK` `mK` `K` `kK`                                              |
| Angle       | `rad` `deg` `rev`                                                              |
| Data        | `bit` `byte` `KB` `MB` `GB` `KiB` `MiB` `GiB`                                  |
| Count       | `count` `samples` `pct` `percent`                                              |

`mhz` is megahertz. `KB` is 1,024 bytes, the same as `KiB`. Temperature is Kelvin only.

| Operation              | Rule                                                   | Error                                                                                   |
| ---------------------- | ------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| `+`, `-`, `%`, compare | Units must have the same dimension, or one has no unit | `incompatible dimensions: length^1 vs time^1`                                           |
| `*`, `/`               | Always allowed                                         |                                                                                         |
| `^`                    | A value with a unit needs a literal integer exponent   | `power operation with dimensioned base requires a literal integer exponent: dimensions` |
| `^`                    | The exponent has no unit                               | `exponent in power operation must be dimensionless, got time^1: dimensions`             |

Arc has no compound units such as `m/s`. A product or a quotient of two values with a
unit is a number with no unit: `2s / 500ms` is `4`.

A duration literal in a variable has the unit of its suffix: `d := 5s` is an `i64 s`.
Timer parameters have the type `i64 ns`, and accept a variable in any time unit:

```arc channels="vent_vlv_cmd, start_cmd" bodies="vent"
import time

hold := 5s

sequence vent {
    1 -> vent_vlv_cmd
    time.wait(duration=hold)
    0 -> vent_vlv_cmd
}

start_cmd == 1 => vent
```

A value converts when it meets another unit of the same dimension. A calculation uses
the smaller unit. A variable, an input, and a function result use their own unit.

| Code, with `d := 1min` | Result                                                          |
| ---------------------- | --------------------------------------------------------------- |
| `d + 30s`              | `90`, in `s`                                                    |
| `120s -> d`            | `d` is `2`                                                      |
| `90s -> d`             | `d` is `1`, with a warning that the integer truncates           |
| `t := 90s`, `t -> d`   | `d` is `1`, with a warning that the integer truncates           |
| `p := 5psi`, `p -> d`  | Error, `incompatible dimensions: cannot write psi to 'd' (min)` |
| `q i64 Pa := 5psi`     | `q` is `34473`, with a warning that the integer truncates       |
| `[1s, 500ms]`          | `[1000, 500]`, in `ms`                                          |
| `ys = xs`              | Error, `'ys' is a series in ms and cannot take a series in s`   |
