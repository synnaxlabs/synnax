## Comments

`//` starts a comment that ends at the end of the line. `/* */` encloses a comment that
can span lines.

```arc channels="tank_pt, tank_pt_kpa"
// Convert psi to kPa.
/* A block comment
   can span lines. */
tank_pt * 6.895 -> tank_pt_kpa // A comment after code
```

## Identifiers

An identifier names a variable, function, sequence, stage, or channel.

- It starts with a letter or `_`.
- It continues with letters, digits, or `_`.
- It is case-sensitive: `tank_pt` and `Tank_PT` are different names.
- It cannot be a keyword.

A `-` is not part of an identifier, so `ox-pt-1` reads as `ox - pt - 1`. The exception
is a Core that runs with channel name validation off (see the
[CLI reference](/reference/enterprise/cli-reference)). Then `-` joins an identifier,
except where it starts `->` or `-=`.

### Keywords

These words are reserved. You cannot use them as identifiers.

| Group       | Keywords                                                               |
| ----------- | ---------------------------------------------------------------------- |
| Declaration | `func` `sequence` `stage` `authority` `import` `as`                    |
| Control     | `if` `else` `for` `break` `continue` `return` `next`                   |
| Operators   | `and` `or` `not`                                                       |
| Literals    | `true` `false`                                                         |
| Types       | `i8` `i16` `i32` `i64` `u8` `u16` `u32` `u64` `f32` `f64` `str` `bool` |
| Type forms  | `chan` `series`                                                        |

Arc has no `while` keyword. Loops use `for`. See
[statements](/reference/control/arc/reference/statements).

## Literals

| Literal         | Form                       | Default type                                          |
| --------------- | -------------------------- | ----------------------------------------------------- |
| Integer         | `42`, `-7`                 | `i64`                                                 |
| Float           | `3.14`, `5.`, `.25`        | `f64`                                                 |
| Number and unit | `50ms`, `10min`, `14.7psi` | The value in the base unit: `50ms` is `50000000` (ns) |
| Boolean         | `true`, `false`            | `bool`                                                |
| String          | `"text"`, `` `text` ``     | `str`                                                 |
| Series          | `[1.0, 2.0, 3.0]`          | `series f64`                                          |

Numbers are decimal only. Hex (`0xFF`), scientific (`1e3`), and `_` separators (`1_000`)
are not numbers: Arc reads the part after the digits as a unit and fails with
`unknown unit: xFF`. A literal takes its type from where you use it. See
[numeric literals](/reference/control/arc/reference/types#numeric-literals).

### Units

A unit name directly after a number, with no space, gives the number a unit: `50ms`,
`10min`. Arc stores the value in the base unit, so `14.7psi` is `101352.97` (Pa). See
[units](/reference/control/arc/reference/types#units).

### Strings

A string in `"..."` stays on one line. A string in `` `...` `` can span lines.

| Escape   | Meaning                             |
| -------- | ----------------------------------- |
| `\n`     | Newline                             |
| `\t`     | Tab                                 |
| `\r`     | Carriage return                     |
| `\b`     | Backspace                           |
| `\f`     | Form feed                           |
| `\\`     | Backslash                           |
| `\"`     | Double quote, in `"..."` only       |
| `` \` `` | Backtick, in `` `...` `` only       |
| `\uXXXX` | Unicode character with 4 hex digits |

Arc keeps any other `\` sequence as written: `"\z"` is the two characters `\z`.

A prefix before the quote changes the string:

| Prefix       | Effect                                                    |
| ------------ | --------------------------------------------------------- |
| `r`          | Raw: escapes stay as written. `r"C:\data"` keeps the `\`. |
| `f`          | Format: `{expr}` inserts the value of an expression.      |
| `rf` or `fr` | Raw and format.                                           |

### Format strings

In an `f` string, `{expr}` inserts the value of `expr`. `{expr:spec}` formats the value
with a spec. A placeholder can hold a number, a `str`, or a `bool`. With no spec, a
number prints in its shortest form: `{p}` with `3.0` gives `3`. A `bool` takes no spec:
`{b:s}` fails with `cannot format type bool`. Write `{{` for a literal `{` and `}}` for
a literal `}`.

```arc channels="tank_pt, tank_msg" bodies="describe"
func describe() {p f64} str {
    return f"Tank at {p:.1f} psi"
}

tank_pt -> describe() -> tank_msg
```

A spec has the form `[flags][width][.precision]verb`. Only the verb is necessary. The
compiler checks the verb against the type of the value.

| Verb     | Types   | Output                      | Example                  |
| -------- | ------- | --------------------------- | ------------------------ |
| `d`      | Integer | Decimal                     | `42` -> `42`             |
| `b`      | Integer | Binary                      | `5` -> `101`             |
| `o`, `O` | Integer | Octal, `O` adds `0o`        | `8` -> `10`, `0o10`      |
| `x`, `X` | Integer | Hex, lowercase or uppercase | `255` -> `ff`, `FF`      |
| `c`      | Integer | Unicode character           | `65` -> `A`              |
| `f`      | Float   | Decimal                     | `3.14` -> `3.140000`     |
| `e`, `E` | Float   | Scientific                  | `3.14` -> `3.140000e+00` |
| `g`, `G` | Float   | Shortest form               | `3.14` -> `3.14`         |
| `s`      | `str`   | The string                  | `ok` -> `ok`             |
| `q`      | `str`   | Quoted, with escapes        | `ok` -> `"ok"`           |

| Flag    | Effect                                       | Example              |
| ------- | -------------------------------------------- | -------------------- |
| `#`     | Adds `0b`, `0`, or `0x` for `b`, `o`, or `x` | `{n:#x}` -> `0xff`   |
| `+`     | Shows the sign of a positive number          | `{n:+d}` -> `+42`    |
| (space) | Puts a space before a positive number        | `{n: d}` -> ` 42`    |
| `-`     | Aligns left in the width                     | `{n:-5d}` -> `42   ` |
| `0`     | Pads with zeros to the width                 | `{n:05d}` -> `00042` |

The width is the minimum number of characters: `{n:5d}` gives `   42`. The precision is
the number of digits after the decimal point: `{p:.2f}` gives `3.14`.

## Imports

The standard library is in modules. Import a module before you use its members.

| Form  | Example                 | Use the member as |
| ----- | ----------------------- | ----------------- |
| One   | `import time`           | `time.wait()`     |
| Alias | `import time as t`      | `t.wait()`        |
| Group | `import ( math  time )` | `math.avg()`      |

The modules are `control`, `math`, `ranges`, `stable`, `status`, and `time`. See the
[standard library](/reference/control/arc/standard-library).

```arc channels="tank_pt, tank_pt_avg, vent_vlv_cmd"
import (
    math
    time as t
)

tank_pt -> math.avg(duration=1s) -> tank_pt_avg
t.interval(period=1min) -> vent_vlv_cmd
```

| Rule                                   | Error                                                                   |
| -------------------------------------- | ----------------------------------------------------------------------- |
| Imports come before all other code.    | `import statements must appear before any other top-level declarations` |
| Each module must exist.                | `unknown module "foo"`                                                  |
| Each import must be used.              | `imported module "time" is unused` (code `ARC5001`)                     |
| A member of a module needs the import. | `undefined symbol: time`, with a note to add `import time`              |

The graph editor adds imports for you.

## Authority declaration

An `authority` declaration sets the control authority of the automation on the channels
that it writes. Values are integers from 0 to 255.

| Form                 | Example                            |
| -------------------- | ---------------------------------- |
| Default              | `authority 100`                    |
| Default and channels | `authority (100 vent_vlv_cmd 200)` |
| Channels only        | `authority (vent_vlv_cmd 200)`     |

Authority declarations come after the imports and before all other code. You can write
more than one. A second default fails with `multiple default authority values`, and a
repeated channel fails with `duplicate authority for 'vent_vlv_cmd'`.

With no declaration, the automation writes at 255. Always give a default. A per-channel
form without a default leaves the other channels, and their index channels, at 255. See
[set authority in an Arc automation](/reference/control/authority?client=arc#set-authority).

## Program structure

A program is a list of top-level items, in this order:

1. Imports.
2. Authority declarations, if you need them.
3. Functions, flows, sequences, stages, and constants, in any order.

```arc channels="tank_pt, high_alarm, press_vlv_cmd, start_cmd" bodies="over, press"
import time

authority 100

limit := 500.0

func over() {p f64} u8 {
    if p > limit {
        return 1
    }
    return 0
}

tank_pt -> over() -> high_alarm

sequence press {
    1 -> press_vlv_cmd
    time.wait(duration=5s)
    0 -> press_vlv_cmd
}

start_cmd == 1 => press
```

You cannot reassign a top-level variable. To change a value, declare it in a function,
stage, or sequence. See [variables](/reference/control/arc/reference/variables).

Braces enclose the body of a function, sequence, or stage. In a sequence or stage body,
newlines, commas, or both separate the items.
