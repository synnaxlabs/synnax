More than one writer can write to the same channel. A writer is a schematic, an Arc
automation, or a script that sends commands. Only one writer at a time has control of a
channel. Synnax uses control authority to decide which writer has control. With control
authority, you can hand off control:

- Between a manual operator and an automated system.
- Between two or more manual operators.
- Between two or more automated systems, such as a nominal control loop and an abort
  sequence.

<Divider.Divider x />

## How authority works

Each writer has an authority from 0 to 255 on each of its channels. 0 is the lowest
authority and 255 is the highest. An authority of 255 is absolute: other writers cannot
take control from it.

- **Higher authority wins.** When a writer opens with a higher authority, it takes
  control from the writer that had control. Synnax ignores the values from writers that
  do not have control.
- **Equal authority: first in wins.** When two writers have the same authority, the
  writer that took control first keeps it.
- **Control returns on release.** When a writer closes or lowers its authority, the
  writer with the next highest authority gets control.

A writer can change its authority while it runs. It can raise its authority to take
control, and lower it to release control.

<Divider.Divider x />

## Example: operator and abort sequence

1. Writer A opens on channel `my-channel` with authority 100.
2. Writer B watches for abort conditions. It opens on `my-channel` with authority 50.
   Writer A keeps control.
3. Writer A writes samples to the channel to command an actuator.
4. Writer B finds an abort condition and sets its authority to 250. Writer B takes
   control of the channel and moves the system into a safe state.
5. An operator (writer C) opens on `my-channel` with authority 255. Writer C takes
   absolute control to make adjustments.
6. Writers B and C close. Control goes back to writer A.

## Where authority is set

- **Schematics**: each schematic writes at the authority in its component toolbar
  `Control` tab. The default is 1. A control chip on a symbol raises the authority of
  that symbol's channel to 255. Refer to
  [manual control](/reference/control/manual#control-authority-on-a-schematic).
- **Arc**: an automation writes at 255 if it does not declare an authority. Refer to
  [control authority in Arc](/reference/control/arc/concepts/control-authority).
- **Code**: a writer from the Python or TypeScript client opens at 255 if you do not set
  its authority. Refer to [authority in code](#authority-in-code).

Because 255 is the default for Arc and for code, an operator cannot take a channel from
them with a schematic. Give these writers an authority below 255 on each channel that an
operator can need to control by hand.

## Authority in code

<Edition.Enterprise>

Writers from the Python and TypeScript clients open with an authority of `ABSOLUTE`
(255). No other writer can write to the channel while the writer is open. Use the
`authorities` parameter to set a lower authority.

</Edition.Enterprise>

### Same authority on all channels

To open a writer with the same authority on all channels, pass the `authorities`
parameter with an integer.

<Client.Tabs client:load exclude={["cpp","console"]}>

  <Fragment slot="python">

```python
writer = client.open_writer(
    start=sy.TimeStamp.now(),
    channels=["time", "temperature"],
    authorities=100,
)
```

  </Fragment>

  <Fragment slot="typescript">

```typescript
const writer = await client.openWriter({
  start: TimeStamp.now(),
  channels: ["time", "temperature"],
  authorities: 100,
});
```

  </Fragment>
</Client.Tabs>

### Different authorities per channel

To open a writer with a different authority on each channel, pass the `authorities`
parameter with a list of integers. The list must have the same length as the list of
channels in the writer.

<Client.Tabs client:load exclude={["cpp","console"]}>

  <Fragment slot="python">

```python
writer = client.open_writer(
    start=sy.TimeStamp.now(),
    channels=["time", "temperature"],
    authorities=[100, 200],
)
```

  </Fragment>

  <Fragment slot="typescript">

```typescript
const writer = await client.openWriter({
  start: TimeStamp.now(),
  channels: ["time", "temperature"],
  authorities: [100, 200],
});
```

  </Fragment>
</Client.Tabs>

### Adjusting authority after open

To change the authority of a writer while it runs, use the <Client.Var client:load
py="set_authority" ts="setAuthority" /> method.

<Client.Tabs client:load exclude={["cpp","console"]}>

  <Fragment slot="python">

```python
# Set the authority on all channels
writer.set_authority(200)

# Set the authority on specific channels
writer.set_authority({
    "time": 150,
    "temperature": 250,
})
```

  </Fragment>

  <Fragment slot="typescript">

```typescript
// Set the authority on all channels
await writer.setAuthority(200);

// Set the authority on specific channels
await writer.setAuthority({
  time: 150,
  temperature: 250,
});
```

  </Fragment>
</Client.Tabs>

This example changes the authority during a write session:

<Client.Tabs client:load exclude={["cpp","console"]}>

  <Fragment slot="python">

```python
with client.open_writer(
    start=sy.TimeStamp.now(),
    channels=["time", "temperature"],
    authorities=100,
) as writer:
    # Start with low authority
    writer.write({"time": sy.TimeStamp.now(), "temperature": 25.0})

    # Increase authority to take control from other writers
    writer.set_authority(200)
    writer.write({"time": sy.TimeStamp.now(), "temperature": 26.0})

    # Release control by lowering authority
    writer.set_authority(50)
```

  </Fragment>

  <Fragment slot="typescript">

```typescript
const writer = await client.openWriter({
  start: TimeStamp.now(),
  channels: ["time", "temperature"],
  authorities: 100,
});
try {
  // Start with low authority
  await writer.write({ time: TimeStamp.now(), temperature: 25.0 });

  // Increase authority to take control from other writers
  await writer.setAuthority(200);
  await writer.write({ time: TimeStamp.now(), temperature: 26.0 });

  // Release control by lowering authority
  await writer.setAuthority(50);
} finally {
  await writer.close();
}
```
